# 第10章　指数と対数

## 10.1 目盛りを決める

第3部では、関数を作ります。関数の値は、たいてい整数になりません。そこでこの章から、数を **目盛り** で持ちます。

```
1 にあたる整数 S = 10⁴⁰
1.5  → 15 × 10³⁹
0.25 → 25 × 10³⁸
```

目盛りの数は、ただの整数です。足し算はそのまま、目盛りどうしの掛け算は「整数の積を S で割る」です。割り算は、第6章の倍々の梯子を上から引くだけで済みます。

S は 10 の累乗にしましたが、第3章の 3120 の累乗でも同じように動きます。10 にしたのは、人が読むときに小数として読みやすいからです。

## 10.2 指数は、自分の一部を足し続けること

「自分の 1/n を自分に足す」ことを n 回繰り返します。

```
x ← x + x ÷ n      （n 回）
```

n を大きくするほど、結果はある一つの数に近づきます。それが e です。

| n | 結果 | ひとこと |
|---:|---|---|
| 1 | 2.000000000000 | 一度に全部足す |
| 2 | 2.250000000000 | 半分ずつ二回 |
| 12 | 2.613035290224 | 毎月 |
| 100 | 2.704813829421 | |
| 3120 | 2.717846334319 | 一周の番地の数だけ |
| 100000 | 2.718268237174 | |
| 級数 | 2.718281828459045235360287471352 | 1 + 1 + 1/2 + 1/6 + … |

この足し方だと、n を大きくしても e に近づく速さはゆっくりです。速く近づけるには、足す項を順に作っていきます。

```
項 ← 項 ÷ k    （k = 1, 2, 3, …）
e = 1 + 1 + 1/2 + 1/6 + 1/24 + …
```

項を k で割って足すのを 36 回繰り返すと、目盛りの 40 桁が埋まります。

```python:code/b13_explog.py
def e_compound(n: int) -> int:
    """(1 + 1/n)^n：x ← x + x÷n を n 回。"""
    x = S
    for _ in range(n):
        x += ladder_div(x, n)
    return x


def e_series() -> Tuple[int, int]:
    """1 + 1 + 1/2 + 1/6 + …：項を k で割っては足す。戻り値 (e, 足した項の数)。"""
    term, total, k = S, S, 1
    while term:
        term = ladder_div(term, k)
        total += term
        k += 1
    return total, k
```

e^x も同じ形で、項を作るたびに x を一つ掛けます。

```
項 ← 項 × x ÷ k
```

x が大きいときは、先に半分を何回かとってから計算し、最後に同じ回数だけ二乗します。

## 10.3 対数は、二乗して数えること

2 を底とする対数（log₂ x）は、次の手順で 1 桁ずつ出ます。

1. x を 2 で割れるだけ割ります。割れた回数が整数部分です。x は 1 以上 2 未満になります。
2. x を二乗します。
3. 2 を越えたら、半分にして桁 **1** を書きます。越えなければ桁 **0** を書きます。
4. 2 に戻ります。

書いた桁は 2進の小数の桁です。1/2, 1/4, 1/8, … として足したものが、対数の小数部分です。

```python:code/b13_explog.py
def log2_fx(x: int, bits: int = 133) -> Tuple[int, List[int]]:

    for _ in range(bits):

            frac_bits.append(1)       # 桁 1

```

自然対数は、log₂ x に ln 2 を掛けたものです。ln 2 は「半分にしては k で割って足す」で作ります。

```
ln 2 = 1/2 ÷ 1 + 1/4 ÷ 2 + 1/8 ÷ 3 + …
```

第5章の計算尺では、目盛りが「1 を何回倍にしたか」でした。この章の対数は、その目盛りを 1 より細かく刻んだものです。整数部分が倍にした回数、小数部分が二乗で読んだ桁です。

## 10.7 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。

- (1 + 1/n)ⁿ が e に近づくことは、ヤコブ・ベルヌーイが複利の問題として調べました（1683年）。
- e = Σ 1/k! と e^x = Σ xᵏ/k! はテイラー展開（マクローリン展開）です。
- 二乗して 2 を越えたら半分にする対数の求め方は、2進の対数を1桁ずつ出す古典的な方法です。
- ln 2 = Σ 1/(k·2ᵏ) は、ln(1 − x) の展開に x = 1/2 を入れたものです。
- 確かめた範囲 [計算]：観察者側で 60 桁の小数計算と照らし合わせました。e、e^x（x = 1, 3, 5, −1）、ln x（x = 2, 3, 13, 3120）、log₂ 3 は、どれも 10⁻³⁵ より小さい差で一致しました。

## 10.8 この章のまとめ

指数も対数も、足し算と倍々の梯子で作れます。

- 数は「1 を 10⁴⁰ とする整数」の目盛りで持ちます。
- 指数は、自分の一部を自分に足し続けることです。項を k で割っては足せば、e も e^x も速く近づきます。
- 対数は、二乗して 2 を越えた回数を、桁として書いていくことです。
- 第5章の計算尺の目盛り（倍にした回数）を、1 より細かく刻んだものが対数です。
