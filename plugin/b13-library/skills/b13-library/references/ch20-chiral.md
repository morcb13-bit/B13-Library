# 第20章　右と左の一個差

## 20.1 右手と左手

分子には、右手と左手のように、鏡に映すと重なる二つの型を持つものがあります。二つの型は、つくっている原子も、原子のつながり方も同じです。違うのは向きだけです。

生き物の体をつくるアミノ酸は、ほとんどが片方の型だけでできています。薬でも、片方の型だけが効き、もう片方は効かないか害になる、ということが起こります。片方の型だけをつくり分けることを、**不斉合成**と呼びます。

2026年10月7日、この不斉合成の研究に、ノーベル化学賞が贈られることになりました。受賞者は東京理科大学の硤合憲三名誉教授と、フランスのアンリ・カガン博士です。授賞理由は「不斉有機合成における非線形効果と自己触媒の発見」です[^1][^2][^3]。

硤合先生は1990年に、できた分子が、自分と同じ型の分子をつくる触媒になる反応を報告しました[^4]。1995年には、2%のわずかな偏りが、この反応で88%まで増幅されることを示しています[^5][^6]。その後の研究では、ごくわずかな偏りから3回の反応で、99.5%以上に達することも示されました[^7]。

この章では、二つのことを足し算と比較だけで書きます。一つは、右か左かを整数の符号として書くことです。もう一つは、わずかな偏りが全体へ広がるための条件です。化学反応そのものを再現するのではありません。同じ出来事を、足し算だけの規則に写して確かめます。

## 20.2 右か左かは、整数の符号で決まる

硤合反応でできる分子の一つ、1-[2-(tert-ブチルエチニル)ピリミジン-5-イル]-2-メチルプロパン-1-オールを例にとります。中心の炭素に、4つのものが付いています。

| 腕 | 付いているもの |
|---|---|
| H | 水素 |
| OH | ヒドロキシ基 |
| iPr | イソプロピル基 |
| 環 | ピリミジン環 |

中心の炭素を原点に置き、4本の腕の先の原子の位置を、0.01Å を 1 とする整数で書きます（座標の作り方は 20.8 節）。

```
H   = (33, −43, −95)
OH  = (27, −99, 100)
iPr = (83, 127, 30)
環  = (−148, 23, −4)
```

4本の腕は、長さも向きもそろっていません。腕の先がつくる形は、正四面体ではなく、ただの四面体です。

右か左かは、この四面体の向きで決まります。H から他の3つへ向かう矢印を並べて、行列式をとります。

$$
s = \det[\,\mathrm{OH}-\mathrm{H},\ \mathrm{iPr}-\mathrm{H},\ \mathrm{環}-\mathrm{H}\,]
$$

行列式は、掛け算と足し算だけで計算できます（掛け算は足し算の繰り返しです。第4章）。

```python:code/b13_chiral.py
def det3(u: Vec, v: Vec, w: Vec) -> int:
    return (u[0] * (v[1] * w[2] + -(v[2] * w[1]))
            + -(u[1] * (v[0] * w[2] + -(v[2] * w[0])))
            + u[2] * (v[0] * w[1] + -(v[1] * w[0])))


def hand(m: dict) -> int:
    """四面体の向き det[OH−H, iPr−H, 環−H]。符号が右か左かを決める。"""
    return det3(sub(m["OH"], m["H"]), sub(m["iPr"], m["H"]), sub(m["環"], m["H"]))
```

この座標では、片方の型（R体）で $s = 8122130$、鏡に映したもう片方の型（S体）で $s = -8122130$ になります。

分子をどう回しても、この符号は変わりません。鏡に映したときだけ、符号が裏返ります。座標の軸を入れ替えたり、向きを反転したりする整数の行列は48通りあります。そのうち回転にあたる24通りでは、符号はすべて保たれました。鏡映を含む24通りでは、すべて裏返りました（実行例）。

**右と左の違いは、＋と−の違いです。** 第1章の平衡進法で、一つの桁が＋と−の向きを持っていたのと同じ立場です。

## 20.3 つくり分けるには、型紙が要る

右か左かの一方だけをつくるには、片方の型だけを受け入れる型紙が要ります。

OH・iPr・環の3つを受ける受け口を持った板を考えます。受け口の三角形は、R体とS体で同じ形です。辺の長さの二乗は、どちらも 59112、65333、56325 です。そのため、受け口が3つあるだけでは、どちらの型も三角形をぴったり合わせられます。

違いが出るのは、板に表と裏があるときです。3つの受け口に合わせると、R体では H が板の表側に来ます。S体では、H が板の裏側に突き抜けます。H がどちらの側に来るかも、行列式の符号で判定できます。

```python:code/b13_chiral.py
def side(m: dict) -> int:
    """受け口 OH・iPr・環 の面に対して、H がどちらの側にあるか（符号）。"""
    return det3(sub(m["iPr"], m["OH"]), sub(m["環"], m["OH"]), sub(m["H"], m["OH"]))
```

この模型で右と左をつくり分けるには、3つの受け口に加えて、表と裏を区別する拘束が要ります。

型紙をどこから持ってくるかで、つくり分けには二つの道があります。

1. **外から型紙を与える。** 片方の型だけでできた触媒を型紙にして、反応のたびに同じ型をつくります。
2. **できたものが型紙になる。** 硤合反応では、できた分子そのものが、次の分子をつくるときの型紙の一部になります。最初にわずかに多かった側が、自分と同じ型を写していきます。

- **② 重ねてみる**：S体を回して、中心の炭素・iPr・環の3つをR体に重ねます。重ねたとき、OH と H の場所が入れ替わります。どう回しても、4つは同時にそろいません。

ドラッグで見る向きを変えられます。右か左かの判定は整数の行列式で、画面に描くための回転と遠近だけが作図用の小数です。

## 20.5 できたものが型紙になると、差が足し込まれる

ここからは、二つ目の道（できたものが型紙になる）を、足し算の規則に写します。右型の数を $N_+$、左型の数を $N_-$、差を $D = N_+ - N_-$ とします。

どの分子も互いに出会える器を考えます。持つのは個数だけです。操作は二つです。

- **写す**：どの分子も、自分と同じ型を1個つくる。$N_+ \to N_+ + N_+$、$N_- \to N_- + N_-$。差も $D \to D + D$ と足し込まれます。
- **組で抜ける**：右型と左型が組になり、両方とも働かなくなる。少ない側の数だけ、両側から同じ数を引きます。差 $D$ は変わりません。

材料は10万個で、尽きるまで写します。材料を配るときは割り算を使わず、多い側から1個ずつ交互に配ります。

```python:code/b13_chiral.py
def vessel(R: int, L: int, food: int, grow: bool, pair: bool, steps: int = 60) -> tuple:
    for _ in range(steps):
        if grow:
            ...                                    # 多い側から1個ずつ交互に配って、同じ型を写す
            R, L = R + gr, L + gl
        if pair:
            m = R if R < L else L
            R, L = R + -m, L + -m
    return R, L
```

| 操作 | 右51・左50 から | 右50・左50 から |
|---|---|---|
| どちらもしない | (51, 50) | (50, 50) |
| 写すだけ | (50307, 49794) | (50050, 50050) |
| 組で抜けるだけ | (1, 0) | (0, 0) |
| 写す＋組で抜ける | (99901, 0) | (0, 0) |

読み方です。

- **写すだけ**では、差は 1 から 513 まで増えます。それでも両側はほぼ半々のままです。差が増えることと、片側にそろうことは別のことです。
- **組で抜けるだけ**では、片側だけにはなりますが、残るのは1個です。少ない側を消しただけで、偏りが広がったわけではありません。
- **写す＋組で抜ける**で、1個の差から、99901個がすべて右型になりました。左を1個多くして始めると、すべて左型になります。同数から始めると、何も残りません。

## 20.6 隣としか出会えないと、混ぜる操作が要る

器では、どの分子も互いに出会えました。次に、60個の席が輪になっていて、各席が両隣としか出会えない場合を考えます。

最初に、10席おきに右と左を交互に3個ずつ置き、その間に右を1個だけ足します。操作は三つです。

- **写す**：空いた席は、両隣を足し、正なら右、負なら左で埋まる（右を +1、左を −1 として）。
- **組で消える**：右と左が隣り合うと、両方とも空席に戻る。
- **混ぜる**：型を見ずに、席を $k$ 飛びに読み直して並べ替える。

```python:code/b13_chiral.py
def ring_step(x: list, copy: bool, pair: bool, k: int) -> list:
    y = list(x)
    if copy:                                       # 写す：空いた席を両隣の和の符号で埋める
        for i in range(N):
            if x[i] == 0:
                s = x[i - 1] + x[(i + 1) % N]
                if s > 0: y[i] = 1
                elif s < 0: y[i] = -1
    if pair:                                       # 組で消える：隣り合った右と左を空席に戻す
        ...
    if k:                                          # 混ぜる：席を k 飛びに読み直す（型は見ない）
        ...
    return y
```

| 操作 | 右を足す | 左を足す | 足さない |
|---|---|---|---|
| 混ぜるだけ | (4, 3) | (3, 4) | (3, 3) |
| 写すだけ | (30, 25) | (25, 30) | (27, 27) |
| 写す＋組で消える | (29, 24) | (24, 29) | (27, 27) |
| 写す＋混ぜる | (32, 24) | (24, 32) | (27, 27) |
| 写す＋組で消える＋混ぜる | (60, 0) | (0, 60) | (0, 0) |

括弧の中は、200歩のあとの（右, 左）の数です。

隣としか出会えないと、写して組で消えても、右の領域と左の領域が境目で向かい合ったまま止まります。組で消える席が境目にしか生まれないからです。混ぜると、右と左が輪のあちこちで出会い、少ない左から先に尽きます。混ぜる飛び幅を 7・11・13・17 と変えても、結果は同じ (60, 0) でした。

試した組み合わせの中で、1個の差が60席すべてを片側で満たしたのは、**写す・組で消える・混ぜる**の三つがそろったときだけでした。

## 20.9 観察者側の整理

既存の化学の名前との対応です。確かめた範囲の行のほかは、出典または Claude の知識によるもので、この本では検算していません。

- 右と左の型は**鏡像異性体（エナンチオマー）**、右か左かを持つことは**キラリティー**と呼ばれます。R体・S体は、中心の炭素の4つの腕に順位をつけて決める呼び名です。
- 生き物のアミノ酸がほぼ片方の型だけでできていることは、**ホモキラリティー**と呼ばれ、その起源は生命の起源に関わる問いとして残っています。
- 片方の型だけでできた触媒で一方をつくる道は、2001年にノーベル化学賞を受けた野依良治先生らの不斉触媒の道です[^11]。
- カガン博士らは1986年の論文で、触媒の偏りと生成物の偏りが比例しない**非線形効果**を報告しました[^8]。この章の「組で抜ける」は、右と左が同時にあると増幅に寄与しない、という抽象化した規則です。実際の反応で起きている錯体の形成や反応の速さを、この一規則で表しているわけではありません。
- 近年の機構研究では、硤合反応の触媒の本体は、できたアルコールがアルデヒドに付いてできる一時的な亜鉛の錯体だとされています[^9]。この章の「写す」は、その二段を一段にまとめたものです。「混ぜる」は、溶液がかき混ぜられていることを抽象化した対応です。
- 型紙が3つの受け口で右と左を見分けるという考え方は、化学では**三点結合の模型**として知られているものに当たります。四点で考える模型などもあります。この章で確かめたのは、この模型の中で、3つの受け口に加えて表と裏の区別が要ることだけです。
- 確かめた範囲 [計算]：上の実行例の数（行列式の符号、48通りの行列、受け口の三角形と H の側、器の4通り、輪の5通りと飛び幅4通り）を確かめました。

## 20.10 この章のまとめ

右と左の違いは、整数の符号の違いです。

- 分子の4本の腕が正四面体でなくても、腕の先がつくる行列式の符号で、右か左かが決まります。回しても符号は変わらず、鏡に映すと裏返ります。
- この模型で一方だけを選ぶには、3つの受け口に加えて、表と裏を区別する型紙が要ります。
- できたものが型紙になると、差が足し込まれて増えます。ただし、写すだけでは両側が半々のままです。
- 右と左が組で抜けると、差を保ったまま、少ない側が先に尽きます。
- 隣としか出会えないときは、混ぜる操作が加わってはじめて、1個の差が全体を片側で満たしました。

1995年に示された「わずかな偏りが大きな偏りへ増幅される」という現象を、足し算と比較だけの規則に写すと、この規則とこの検定の範囲では、写す・組で抜ける・混ぜるの三つがそろったときに、同じ種類の増幅が現れました。
