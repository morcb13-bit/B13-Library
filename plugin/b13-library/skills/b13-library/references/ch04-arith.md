# 第4章　四則

## 4.1 第1章で済んでいるもの

足し算と引き算は、第1章で済んでいます。

| 演算 | やること |
|---|---|
| 足す | 桁ごとに足し、はみ出したら N を一つ引いて上へ ±1 を送る |
| 引く | 符号を裏返して足す |

この章では、残りの二つ（掛け算と割り算）を、この二つと「符号を読む」だけで組みます。道具は平衡13進です。

もう一つ使う操作が **ずらす** です。13 の位へずらすのは、桁の列の下に 0 を一つ並べるだけです。掛け算はしていません。

## 4.2 掛け算：桁の数だけ足す

b の桁を下から一つずつ見ます。13ᵏ の位の桁が d なら、a を 13ᵏ の位へずらしたものを |d| 回足します。d が負なら、裏返してから足します。

| b の桁 | やること |
|---|---|
| +1 … +6 | ずらした a をその回数足す |
| 0 | 何もしない |
| −1 … −6 | ずらした a を裏返して、その回数足す |

桁は −6〜+6 なので、どの位でも足すのは多くて 6 回です。0〜12 の13進なら 12 回足す桁が出ます。平衡桁では、その半分で済みます。

```python:code/b13_arith.py
def shift(a: Digits, k: int) -> Digits:
    """N^k の位へずらす：下に 0 を k 個並べる。"""
    return trim([0] * k + list(a))


def mul(a: Digits, b: Digits, N: int, log: Log | None = None) -> Tuple[Digits, int]:
    """掛け算。戻り値は (積, 足した回数)。"""
    acc: Digits = [0]
    adds = 0
    for k, d in enumerate(b):
        if d == 0:
            continue
        part = shift(a, k) if d > 0 else neg(shift(a, k))
        for _ in range(abs(d)):
            acc = add(acc, part, N)
            adds += 1
    return acc, adds
```

## 4.3 割り算：半分以内へ寄せる

割り算は、上の位から順に進みます。

1. 余りを a から始めます。
2. 13ᵏ の位へずらした b を用意します。
3. 余りが b と同じ向きで、b の半分より大きければ、ずらした b を引きます。商のこの位に +1。
4. 余りが b と逆向きで、b の半分より大きければ、ずらした b を足します。商のこの位に −1。
5. 余りが b の半分以内に入ったら、一つ下の位へ移ります。

最後の位まで進むと、余りは b の半分以内に着地します。

- **商**は、a ÷ b に一番近い整数です。
- **余り**は、残渣です。|余り| ≤ |b| ÷ 2 で、負にもなります。

「半分より大きいか」は、余りを二つ足して b を引いたものの符号で見ます。比べるのも足し算と符号だけです。

```python:code/b13_arith.py
def _more_than_half(r: Digits, s: Digits, N: int) -> bool:
    """|r| が |s| の半分より大きいか（r と s は同じ向き）を、r+r−s の符号で見る。"""
    return sign(add(add(r, r, N), neg(s), N)) == sign(s)


def divide(a: Digits, b: Digits, N: int, log: Log | None = None) -> Tuple[Digits, Digits, int]:
    """割り算。戻り値は (商, 余り, 足した回数)。a = 商×b + 余り、|余り| ≤ |b|/2。"""
    r = list(a)
    q: Digits = [0] * (len(a) + 2)
    adds = 0
    for k in range(len(a) + 1, -1, -1):
        s = shift(b, k)
        while sign(r) != 0:
            if sign(r) == sign(s) and _more_than_half(r, s, N):
                r = add(r, neg(s), N)
                q[k] += 1
            elif sign(r) == -sign(s) and _more_than_half(neg(r), s, N):
                r = add(r, s, N)
                q[k] += -1
            else:
                break
            adds += 1
    return trim(q), trim(r), adds
```

## 4.7 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。

- 余りを b の半分以内にとる割り算は「最も近い整数への丸め」を伴う割り算で、平衡3進の計算機でも同じ形の割り算が使われていました。
- 確かめた範囲 [計算]：
  - 平衡13進と平衡5進で、a が −400〜400、b が −40〜40 のすべての組を確かめました。積が a × b と一致し、商と余りが「商 × b + 余り = a」「|余り| ≤ |b| ÷ 2」を満たし、商の桁が範囲内に収まりました。
  - |a| ≤ 10⁸、|b| ≤ 10⁴ から無作為に選んだ 3000 組でも、同じことを確かめました。

## 4.8 この章のまとめ

四則が、足す・裏返す・ずらす・符号を読む、の四つでそろいました。

- 掛け算は、b の桁の数だけ、ずらした a を足すことです。平衡桁なら、一つの位で足すのは多くて 6 回です。
- 割り算は、ずらした b を足すか引くかして、余りを b の半分以内へ寄せることです。
- 割り算の答えは「一番近い商」と、正にも負にもなる残渣です。
