# 第14章　差分と和（微分と積分）

## 14.1 引くことと足すこと

列が一つあれば、そこから二つの列が作れます。

```
差分：隣どうしを引く      d[n] = a[n+1] − a[n]
和：  ここまでを足す      s[n] = a[0] + a[1] + … + a[n−1]
```

この二つは、互いに戻します。

- 和を取ってから差分を取ると、元の列に戻ります。足したものの隣どうしを引けば、最後に足した一つが残るからです。
- 差分を取ってから和を取ると、元の列から先頭の数を引いたものに戻ります。差分を足すと、あいだの数が打ち消し合い、端と端の差だけが残るからです。先頭の数を最初に置いておけば、元の列そのものに戻ります。

```python:code/b13_diffsum.py
def diff(a):
    """隣どうしを引く。"""
    return [a[i + 1] + -a[i] for i in range(len(a) - 1)]


def accum(a, start=0):
    """ここまでを足す。先頭は start（何も足していない状態）。"""
    out = [start]
    for x in a:
        out.append(out[-1] + x)
    return out
```

この章で使う操作は、この二つだけです。

## 14.2 差分の表

差分の列から、さらに差分を取ることができます。これを段に重ねたものを **差分の表** と呼びます。

| 段 | n² の表 |
|---|---|
| 列 | 0, 1, 4, 9, 16, 25, 36, 49, 64 |
| 1 段目 | 1, 3, 5, 7, 9, 11, 13, 15 |
| 2 段目 | 2, 2, 2, 2, 2, 2, 2 |
| 3 段目 | 0, 0, 0, 0, 0, 0 |

| 段 | n³ の表 |
|---|---|
| 列 | 0, 1, 8, 27, 64, 125, 216, 343, 512 |
| 1 段目 | 1, 7, 19, 37, 61, 91, 127, 169 |
| 2 段目 | 6, 12, 18, 24, 30, 36, 42 |
| 3 段目 | 6, 6, 6, 6, 6, 6 |
| 4 段目 | 0, 0, 0, 0, 0 |

n² の表は 2 段目で 2 に、n³ の表は 3 段目で 6 に着地し、その下は 0 です。

n² の 1 段目は奇数の列です。第9章で、奇数を引けるだけ引いて整数平方根を出しました。あれは、この表の 1 段目を上から順に引いていたことになります。表を逆向きに読むと、奇数を足していけば平方数が並ぶ、ということです。

## 14.3 左端だけで、表が戻る

表の左端の数（各段の先頭）だけを残して、ほかを消してみます。

```
n² の左端：0, 1, 2, 0
n³ の左端：0, 1, 6, 6, 0
```

これだけで、列全体が戻ります。いちばん下の段は同じ数が並ぶので、そこから一段ずつ和を取って上がればよいからです。和を取るときの先頭の数が、それぞれの段の左端です。

```python:code/b13_diffsum.py
def rebuild(h, length):
    """左端の数だけから列を戻す。いちばん下の段から和を取って上がる。"""
    row = [h[-1]] * length
    for x in reversed(h[:-1]):
        row = accum(row, x)[:length]
    return row
```

戻すやり方はもう一つあります。左端の数に、パスカルの三角形（上の二つを足して作る表）の段を掛けて足すことです。n 番目の数は

```
左端[0] × (三角形の n 段目の 0 番) + 左端[1] × (n 段目の 1 番) + 左端[2] × (n 段目の 2 番) + …
```

で戻ります。たとえば n² の 5 番目は、0 × 1 + 1 × 5 + 2 × 10 = 25 です。

## 14.4 自分が差分になる列

差分を取っても形が変わらない列があります。

| 列 | 差分 | 左端 |
|---|---|---|
| 2ⁿ：1, 2, 4, 8, 16, … | 1, 2, 4, 8, … ＝ 自分 | 1, 1, 1, 1, … |
| フィボナッチ：0, 1, 1, 2, 3, 5, 8, … | 1, 0, 1, 1, 2, 3, 5, … ＝ 一つ前の自分 | 0, 1, −1, 2, −3, 5, −8, … |

- 2ⁿ は、倍々にすること（自分に自分を足すこと）で作った列です。だから隣どうしの差は自分そのものです。左端はすべて 1 で、2ⁿ はパスカルの三角形の n 段目を全部足したものになります。
- フィボナッチ数は、一つ前と二つ前を足して作った列です。だから隣どうしの差は、二つ前、つまり一つずれた自分です。左端には、フィボナッチ数が符号を交互に裏返して並びます。

和の側から見ると、フィボナッチ数を 0 からここまで足したものは、二つ先のフィボナッチ数から 1 を引いたものです。

```
0 + 1 + 1 + 2 + 3 + 5 + 8 = 20 = 21 − 1
```

## 14.5 刻みを細かくする

ここまでは、隣との間隔が 1 の列でした。第10章からの目盛り（1 にあたる整数 S = 10⁴⁰）を使うと、間隔を 1/n にできます。

刻み 1/n で引いて、n 倍します。間隔で割るかわりに、間隔の逆数の整数 n を掛けるだけです。

```python:code/b13_diffsum.py
def square_slope(x, n):
    """x² の、刻み 1/n の傾き：((x + 1/n)² − x²) を n 倍。x は目盛り。"""
    h = ladder_div(S, n)
    sq = lambda v: ladder_div(v * v, S)
    return (sq(x + h) + -sq(x)) * n
```

x² の x = 1 での傾きは、刻みを細かくするほど 2 に近づきます。

| n | 傾き |
|---:|---|
| 1 | 3.000000000000 |
| 10 | 2.100000000000 |
| 100 | 2.010000000000 |
| 3120 | 2.000320512820 |
| 1000000 | 2.000001000000 |

2 から離れている分は、ちょうど 1/n です。刻みを残した分が、残渣として傾きに乗っています。

第10章の e の作り方 x ← x + x ÷ n は、この言葉で言い直せます。刻み 1/n の差分（を n 倍したもの）が、自分そのものになる列です。14.4 の 2ⁿ（刻み 1 で差分が自分）の刻みを細かくしたものが、e の列です。

## 14.6 柱で数える

今度は和の側です。0 から 1 までの x² の下を、幅 1/n の柱 n 本で数えます。

柱の高さを n² 倍すると、整数になります。

```
低い柱（左の端の高さ）：0², 1², 2², …, (n−1)²  の和を L
高い柱（右の端の高さ）：1², 2², 3², …, n²      の和を H
```

面積は「和 ÷ n³」です。平方数は奇数を足して作れる（14.2）ので、L と H は足し算だけで出ます。

```python:code/b13_diffsum.py
def columns(n):
    low = high = sq = 0
    odd = 1
    for k in range(n):
        low += sq            # k² を足す
        sq += odd            # 次の平方（奇数を足す）
        odd += 2
        high += sq           # (k + 1)² を足す
    return low, high
```

L と H を 3 倍して、n³ と比べます。

| n | L | H | n³ | n³ − 3L | 3H − n³ |
|---:|---:|---:|---:|---:|---:|
| 1 | 0 | 1 | 1 | 1 | 2 |
| 2 | 1 | 5 | 8 | 5 | 7 |
| 3 | 5 | 14 | 27 | 12 | 15 |
| 4 | 14 | 30 | 64 | 22 | 26 |
| 5 | 30 | 55 | 125 | 35 | 40 |
| 10 | 285 | 385 | 1000 | 145 | 155 |
| 13 | 650 | 819 | 2197 | 247 | 260 |

- 3L は、いつも n³ より少し小さく、3H は少し大きくなります。面積を 3 倍したものが、n³ をはさんでいます。
- 足りない分 n³ − 3L は 1, 5, 12, 22, 35, … です。これは **五角数** です。1 に 4, 7, 10, 13, … と、3 ずつ増える数を足していった列です。
- はみ出す分 3H − n³ は 2, 7, 15, 26, 40, … です。2 に 5, 8, 11, … を足していった列で、これも 3 ずつ増える数の和です。
- 二つを足すと 3n² です。高い柱と低い柱の差は、いちばん右の柱一本分 n² で、それを 3 倍したものだからです。

n = 1 から 2000 まで、二つの列がそれぞれ五角数の作り方と一致することを、整数の足し算だけで確かめました。

柱を細かくしても、足りない分とはみ出す分は消えません。五角数として残り、n³ に比べて小さくなっていくだけです。

## 14.10 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。この章は、既存の微分・積分を整数の上に離散化して並べたもので、それ以上のことは主張しません。

- 差分と和は、微分と積分の離散の形です。「和の差分は元の列、差分の和は端と端の差」は、微分積分学の基本定理の離散の形にあたります。差分と和を扱う分野は「差分法」「和分法（有限差分の計算）」と呼ばれます。
- 左端の数とパスカルの三角形で列を戻す式は、ニュートンの前進差分公式です。k 次の多項式の差分表は k 段目で一定になり、その値は（最高次の係数）× k! です（n² で 2、n³ で 6）。
- 2ⁿ は差分の世界での指数関数にあたります。連続の側では、微分して自分になるのが eˣ です。刻みを 1/n にした (1 + 1/n)ⁿ が n を大きくすると e に近づくことは、第10章で見ました。
- 刻み h の差分商 (f(x + h) − f(x)) / h は、h を小さくすると微分係数に近づきます。x² では 2x + h で、残る h が 14.5 の 1/n です。
- 柱の和は、リーマン和（左端と右端の和）です。0〜1 の x² の積分は 1/3 です。
- 0² + 1² + … + (n−1)² = (n−1)n(2n−1)/6 から、n³ − 3L = n(3n − 1)/2、3H − n³ = n(3n + 1)/2 が出ます。この二つは、五角数と、その相棒の数（オイラーの五角数定理に出てくる一般化五角数の二つの系列）です。
- 確かめた範囲 [計算]：
  - 上の実行例の数を確かめました。
  - 左端とパスカルの三角形で列が戻ることを、n²・n³・2ⁿ・フィボナッチの 0〜11 番で確かめました。
  - n³ − 3L と 3H − n³ が二つの五角数の列と一致することを、n = 1〜2000 で確かめました。動く図の点の数が n³ − 3L と一致することを、n = 1〜30 で確かめました。
  - 一般の n で成り立つことは、上の和の公式（知識）によるものです。

## 14.11 この章のまとめ

差分と和は、引くことと足すことです。

- 和の差分は元の列、差分の和は端と端の差です。二つは互いに戻します。
- 差分を何段も取ると、n² は 2 段目で 2、n³ は 3 段目で 6 に着地します。左端の数だけから、列全体が戻ります。
- 2ⁿ は差分が自分、フィボナッチ数は差分が一つ前の自分です。刻みを 1/n に細かくすると、差分が自分になる列が e の列（第10章）です。
- 刻みを細かくした傾きには、刻みの分（1/n）が残渣として乗ります。
- x² の下を柱で数えると、n³ と柱の和の 3 倍との差が、五角数として残ります。

次の章では、二つ前・三つ前を足して作る列（漸化式）を、表の足し合わせ（畳み込み）として並べます。
