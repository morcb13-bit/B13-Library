## 0.1+0.2 は 0.3 か

JavaScript や Python で `0.1 + 0.2` を計算すると、答えは `0.30000000000000004` になります。

ほかの式も、JavaScript（Node.js）と Python で実際に走らせてみました。

| 式 | JavaScript・Python | morc 電卓 |
|---|---|---|
| `0.1 + 0.2` | 0.30000000000000004 | ＝ 0.3 |
| `0.1 * 3` | 0.30000000000000004 | ＝ 0.3 |
| `1.1 * 3` | 3.3000000000000003 | ＝ 3.3 |
| `10 / 3 * 3` | 10（途中の 10/3 は 3.3333333333333335） | ＝ 10 |

`10 / 3 * 3` は 10 に戻ります。途中の 10/3 は末尾がずれていますが、3 を掛けたときの丸めで、ずれがたまたま消えるからです。浮動小数では、ずれが表に出るかどうかが数によってまちまちで、前もって読めません。

これは計算機の不具合ではありません。多くの計算機は数を「2 進の浮動小数」で持ちます。0.1 は 2 進では割り切れないため、最初から少しずれた値で入っています。そのずれが足し算で表に出てきたのが、この 4 です（ここまでは計算機の世界でよく知られた話で、B13 の側の言葉ではなく、観察者側の整理です）。

B13 の道具は、数を整数のまま持ち、足し算と大小の比較だけで計算します。この作り方で、普段使いの関数電卓を一つ作りました。

### 式の書き方

| 書き方 | 意味 |
|---|---|
| `=1+2` / `1+2` | 先頭の `=` はあってもなくてもよい |
| `+ - * / ^ %` | 足す・引く・掛ける・割る・べき乗・百分率（`50%` は 0.5）。`×` `÷` も使える |
| `-2^2` は 4 | Excel と同じく、先頭のマイナスがべき乗より先に結びつく |
| `2^3^2` は 64 | Excel と同じく、べき乗は左から計算する |
| `SIN(RADIANS(30))` | 三角関数はラジアン。度は `RADIANS` で直す |
| 「答」キー | 直前の答えを式に入れる |

使える関数は 26 個です。

`SQRT` `PI` `EXP` `LN` `LOG10` `LOG` `SIN` `COS` `TAN` `RADIANS` `DEGREES` `ROUND` `ROUNDUP` `ROUNDDOWN` `INT` `ABS` `MOD` `QUOTIENT` `GCD` `LCM` `FACT` `COMBIN` `POWER` `SUM` `PRODUCT` `AVERAGE`

### 計算例

下の表は、電卓の計算部分をそのまま実行した出力です。「足し算」は、その答えを出すまでに使った足し算の回数です。

| 式 | 答え | 印 | 足し算 |
|---|---|---|---|
| `=0.1+0.2` | ＝ 0.3（分数 3/10） | 正確 | 84 回 |
| `=1/3*3` | ＝ 1 | 正確 | 45 回 |
| `=1/7` | ＝ 0.(142857)（分数 1/7） | 正確 | 31 回 |
| `=SQRT(16/9)` | ＝ 4/3 | 正確 | 161 回 |
| `=-2^2` | ＝ 4 | 正確 | 44 回 |
| `=ROUND(-2.5)` | ＝ −3 | 正確 | 106 回 |
| `=200*15%` | ＝ 30 | 正確 | 145 回 |
| `=GCD(1071,462)` | ＝ 21 | 正確 | 100 回 |
| `=123456789*987654321` | ＝ 121932631112635269 | 正確 | 443 回 |
| `=FACT(30)` | ＝ 265252859812191058636308480000000 | 正確 | 718 回 |
| `=(1+SQRT(5))/2` | ≒ 1.61803398874989484820… | 近似（20 桁） | 65,725 回 |
| `=2^0.5` | ≒ 1.41421356237309504880… | 近似（20 桁） | 64,539 回 |
| `=EXP(1)` | ≒ 2.718281828459045235360287471352… | 近似（30 桁） | 24,704 回 |
| `=PI()` | ≒ 3.14159265358979323846264338327950288419716939937510… | 近似（50 桁） | 33,927 回 |

`=SIN(RADIANS(30))` は ≒ 0.50000000000000000000… と出ます。答えはちょうど 1/2 のはずですが、途中で π を 32 桁で打ち切って使っているので、近似の印が付きます。印は、どこで打ち切りが入ったかを正直に運びます。

## しくみ

### 数は「整数 ÷ 整数」のまま持つ

0.1 は 1/10、0.2 は 1/5 として持ちます。足すと 3/10 なので、答えはちょうど 0.3 です。1/7 も 1/7 のまま持つので、3 倍して 7 で割っても元に戻ります。分数は毎回、互除法で約分します。

小数で表示するときは、10 の累乗を掛けてから割り、指定の桁で切り捨てます。負の数も 0 の向きに切り捨てます。小数が繰り返すときは、繰り返しの部分を（ ）で示します。

### 掛け算と割り算を足し算で組む

中で数に対してしている操作は、足すことと、どちらが大きいかを比べることだけです。

- **引き算**：符号を返して足す。
- **掛け算** a×b：a を自分自身に足して a, 2a, 4a, 8a, … のはしごを作る。b を 1, 2, 4, 8, … の段に分け、同じ段を拾って足す。
- **割り算** a÷b：b のはしご b, 2b, 4b, … を作り、上の段から引けるだけ引く。引いた段の数を足したものが商、残りが余り。
- **10 倍**：2x, 4x, 8x を足し算で作り、8x＋2x。
- **平方根**：答えの候補に 1, 2, 4, … を上の段から足してみて、二乗が元の数を越えなければ採る。

掛け算の「はしご」は、筆算の位取りを 2 進で行っているのと同じものです（観察者側の整理）。

### 終わりのない数には「近似」の印を付ける

√2・π・e・LN・SIN のように小数が終わらない数は、10 の累乗を掛けた整数で計算します。指定の桁より 12 桁多く計算してから打ち切り、「近似」の印を付けます。

- π は 16·atan(1/5) − 4·atan(1/239) を、整数のまま足し引きして求めます。
- EXP は級数 1 + x + x²/2! + … を足し、LN は 2 の累乗と 1〜2 の数に分けてから級数を足します。
- SIN・COS は、角度を 2π で折り返してから級数を足します。

式の中に近似が一つでも入ると、答えも近似になります。分数で表せる答えには「正確」の印が付きます。

### 平衡進数で見る

開閉する欄に、同じ答えを平衡 3 進（−1・0・+1）と平衡 13 進（−6〜+6）で書きます。小数のある答えは、平衡進数にも小数点を付けます。

たとえば −1/7 は、平衡 13 進で 0.−2 +2 −2 +2 … と並びます。−2/13 から始まるこの並びを足し合わせると、ちょうど −1/7 になります。

## 検算

走らせる前に、次の基準を決めました。

- **正確な答えになる式**：分数がぴったり期待どおりで、印が「正確」なら合格。
- **近似になる式**：高精度の計算ライブラリ mpmath（80 桁）の値と、小数 38 桁目までの差が 1 以内で、印が「近似」なら合格。
- **誤った式**：答えを出さず、日本語のエラーを返せば合格。答えを出したら NG。
- **平衡進数**：平衡進数を数に戻し、答えとの差が平衡進数の最後の桁の半分以内なら合格。

結果は次のとおりです。

| 項目 | 件数 | 結果 |
|---|---|---|
| 正確な答えになる式（四則・%・`-2^2`・`2^3^2`・ROUND の端数・MOD と QUOTIENT の負の数など） | 28 | すべて合格 |
| 近似になる式（π・e・EXP・LN・LOG・SIN・COS・TAN・小数乗など） | 18 | すべて合格 |
| 誤った式（0 で割る・閉じ括弧なし・知らない関数・LN(0) など） | 7 | すべて合格 |
| 平衡 3 進・平衡 13 進（π・√2・−e・22/7・0.1+0.2・−1/7・−12345） | 14 | すべて合格 |

計算の芯と同じ作りの道具（下の「答え一発 morc ミニ」）は、別の AI（ChatGPT）にも検算してもらいました。掛け算は −100〜100 の全組み合わせ、割り算は −30〜30 の全組み合わせ、平方根は 0〜10,000、平衡 3 進と平衡 13 進は −10,000〜10,000 で、すべて合格しています。π・e・√2・φ は 200 桁まで外部の値と一致しました。

## まとめ

浮動小数では、0.1+0.2 や 1.1×3 の末尾がずれ、10/3×3 はたまたま戻ります。ずれるかどうかは数によってまちまちです。数を分数のまま持ち、操作を足し算と大小の比較だけに絞ると、どの数でも必ずぴったりになります。0.1+0.2 はちょうど 0.3 になり、1/7 を 7 倍すれば 1 に戻ります。π や √2 のように終わらない数は、指定の桁で打ち切り、そのことを印で示します。

「正確」と「近似」を分けて運ぶので、答えを見ればどこまで信じてよいかがわかります。足し算だけで組んだ関数電卓は、Excel と同じ書き方で、ブラウザとスマホでそのまま使えます。
