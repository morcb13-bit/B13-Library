# b13-library

Zenn の本『Nature Knows Only Addition ― 動く図で読む足し算だけの数学 ―』（B13 ライブラリー）を Claude のプラグインにしたもの。

## 入っているもの

- **b13-library**（スキル）：本の 13 章ぶんの Python コードと章の本文。整数・足し算・比較だけで、平衡N進、φ進と Zeckendorf、3120番地の位相、四則、半加算器と計算尺、互除法と剰余、平方剰余・ピサノ周期・篩、Z[φ]、√n とペル方程式、指数と対数、三角関数、双曲関数、定数の3120展開を計算する。
- **b13-moving-figures**（スキル）：本の動く図 21 枚（HTML 一枚で動く）。見せる・作り直す・新しく作るときの決まり。
