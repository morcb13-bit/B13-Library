十の番地で回す

輪を 10 等分すると、一番地は 36° です。2cos(36°·k) は 2, φ, φ − 1, 1 − φ, −φ, −2, … と、sin(36°·k) ÷ sin 36° は 0, 1, φ, φ, 1, 0, … と、どれも Z[φ] の数（整数の組）になります。この二つの表で列を回すと、変換も、戻すことも、畳み込みも、整数の組だけで済みます。

左の輪は、番地 k の数 x[k] が、m·k 番地（10 で回したもの）に置かれるところです。そこに乗った 2cos と sin 比を掛けて足したものが A[m] と B[m] です。棒の長さは作図用の小数で、数は整数の組で出しています。40·x[k] = Σ 2cos·A + (3 − φ)·Σ sin比·B で、元の列に戻ります。

畳み込みは、変換の側で掛け算になる

直接の畳み込み（輪を一周する、ずらして掛けて足す）と、変換してから番地ごとに 2·A_y = A_x·A_h − (3 − φ)·B_x·B_h、2·B_y = A_x·B_h + B_x·A_h と掛けて戻したものを並べます。どの番地でも同じ整数になります。
