# 第8章　Z[φ]：ノルム・単数・φ倍

## 8.1 整数の組として数を持つ

第2章で、φ の累乗を整数の組 `a + bφ` で持ちました。この章では、その組そのものを数として扱います。整数の組で書ける数の全体を、Z[φ] と書きます。

約束は、第2章と同じ φ² = φ + 1 の一つだけです。

| 操作 | 組の上でやること | ひとこと |
|---|---|---|
| 足す | (a, b) + (c, d) = (a + c, b + d) | 成分ごとに足す |
| 掛ける | (a, b)(c, d) = (ac + bd, ad + bc + bd) | φ² を φ + 1 に置き換えただけ |
| φ 倍 | (a, b) → (b, a + b) | 足し算一回 |
| φ で割る | (a, b) → (b − a, a) | 引き算一回 |
| 共役 | (a, b) → (a + b, −b) | φ を 1 − φ に取り替える |

整数どうしの掛け算は、第4章で足し算に戻してあります。この章のコードでは、整数の掛け算をそのまま使います。

## 8.2 ノルム：組から一つの整数へ

数に、その共役を掛けると、φ の部分が消えて整数が一つ残ります。これを **ノルム** と呼びます。

```
N(a + bφ) = a² + ab − b²
```

B13 で使ってきたノルム形 x² − xy − y² と同じものです（x = a、y = −b と置くと一致します）。

```python:code/b13_zphi.py
def mul(u: Z, v: Z) -> Z:
    a, b = u
    c, d = v
    return (a * c + b * d, a * d + b * c + b * d)


def times_phi(u: Z) -> Z:
    return (u[1], u[0] + u[1])


def conj(u: Z) -> Z:
    return (u[0] + u[1], -u[1])


def norm(u: Z) -> int:
    a, b = u
    return a * a + a * b + -(b * b)
```

ノルムには、性質が二つあります。

- **掛け算をそのまま写す**：N(uv) = N(u) × N(v)。組どうしの掛け算が、整数一つどうしの掛け算に写ります。
- **φ 倍で符号が裏返る**：N(φ) = −1 なので、φ 倍するたびにノルムの符号が裏返り、絶対値は変わりません。

## 8.3 単数：ノルムが ±1 の数

ノルムが ±1 の数を **単数** と呼びます。単数で割っても、Z[φ] の外へ出ません。

φ の累乗はすべて単数です。φᵏ の組はフィボナッチ数で、ノルムは +1 と −1 を交互にとります。

| φᵏ | 組 | ノルム |
|---|---|---:|
| φ⁻² | 2 − 1φ | +1 |
| φ⁻¹ | −1 + 1φ | −1 |
| φ⁰ | 1 + 0φ | +1 |
| φ¹ | 0 + 1φ | −1 |
| φ² | 1 + 1φ | +1 |
| φ³ | 1 + 2φ | −1 |
| φ⁷ | 8 + 13φ | −1 |
| φ⁸ | 13 + 21φ | +1 |

|a|, |b| ≤ 60 の箱の中でノルムが ±1 の組を全部探すと 40 個あり、どれも ±φᵏ でした。単数は φ の累乗と、その符号の裏返しだけです。

## 8.4 ノルムになれる数、なれない数

1 から 31 までの数のうち、どれがノルムになれるかを探します（|a|, |b| ≤ 60 の箱の中で）。

| ノルムになれる | 1, 4, 5, 9, 11, 16, 19, 20, 25, 29, 31 |
|---|---|
| ノルムになれない | 2, 3, 6, 7, 8, 10, 12, 13, 14, 15, 17, 18, … |

なれる素数は 5, 11, 19, 29, 31 です。第7章で「5 が平方になれる」側にあった素数（5 で割った余りが 1 か 4）と、5 自身です。

| 素数 | ノルムとして | ひとこと |
|---|---|---|
| 5 | N(2 + 1φ) | 5 は φ の世界の中心 |
| 11 | N(3 + 1φ) | Z[φ] の中で二つに割れる |
| 19 | N(4 + 1φ) | |
| 29 | N(5 + 1φ) | |
| 31 | N(5 + 2φ) | |
| 13 | なれない | Z[φ] の中でも割れない |

13 はノルムになれません。13 は Z[φ] の中でも、二つの数の積に割れない素数です。B13 では、この割れない 13 を番地の基数に使ってきました。

## 8.5 動く図：φ倍で跳ぶ格子

格子の点 (a, b) を、数 a + bφ として色分けします。ノルムが正なら青、負なら赤です。φ 倍と φ で割るたびに、点が跳びます。

@[codepen](ここに CodePen の URL)

- 点線は、ノルムが 0 になる二本の線です。青と赤の領域の境目です。
- 3 + φ（ノルム +11）から φ 倍すると、1 + 4φ（−11）、4 + 5φ（+11）、… と青と赤を交互に跳びます。ノルムの絶対値は 11 のままです。
- 薄い曲線は、ノルムが +11 と −11 になる点の集まり（双曲線）です。点は、この二本の双曲線の上だけを跳びます。
- 輪で囲んだ点が単数です。1 から跳び始めると、輪の点だけを通ります。

φ 倍を二回すると、ノルムの符号は元に戻り、点は同じ双曲線の上を外へ滑ります。これが、第12章で扱う双曲回転の入口です。

## 8.8 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。

- Z[φ] は、二次体 Q(√5) の整数環です。ノルムが掛け算を写すこと、単数が ±φᵏ だけであること（ディリクレの単数定理の一番小さな場合）が知られています。
- φᵏ のノルムが ±1 になることは、カッシーニの恒等式 F(k−1)F(k+1) − F(k)² = (−1)ᵏ と同じ内容です。
- 素数 p が Z[φ] の中で二つに割れるのは、5 が p の輪で平方になれるとき（p を 5 で割った余りが 1 か 4 のとき）です。2・3・7・13 のように割れない素数を「惰性」と呼びます。5 は φ の世界の中心にあたる素数で、√5 の二乗として現れます（5 = N(2 + φ) で、2 + φ は √5 に単数を掛けたものです）。
- 確かめた範囲 [計算]：
  - |a|, |b| ≤ 99 の無作為な 5000 組で、N(uv) = N(u)N(v)、φ 倍でノルムの符号が裏返ること、φ 倍して φ で割ると元に戻ること、自分と共役の積がノルムに一致することを確かめました。
  - 単数とノルムになれる数は、|a|, |b| ≤ 60 の箱の中を全部探した結果です。箱の外は探していません。

## 8.9 この章のまとめ

整数の組 a + bφ が、足し算だけで数として働きます。

- 掛け算は φ² を φ + 1 に置き換えるだけで、φ 倍は足し算一回、φ で割るのは引き算一回です。
- ノルム a² + ab − b² は組を整数一つに写し、掛け算をそのまま写します。
- 単数は ±φᵏ だけで、組はフィボナッチ数です。
- φ 倍するたびに、数はノルムの絶対値を保ったまま、二本の双曲線の間を跳びます。
- 13 はノルムになれず、Z[φ] の中でも割れません。

次の章では、この組を使って、√n を足し算だけで近づける方法（連分数とペル方程式）を扱います。
