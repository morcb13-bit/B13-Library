# 第13章　定数 π・e・φ・√5・ln2 を3120で展開する

## 13.1 ここまでに作った定数

この本では、五つの定数を足し算だけで作ってきました。

| 定数 | 作った章 | 作り方 |
|---|---|---|
| π | 第11章 | マチンの式。arctan(1/m) の項を割って足す |

## 13.2 3120 の目盛りで読む

読み方は、第3章で一周を n 等分したときと同じ「拡大して、いちばん近い目盛りに着地させる」です。

1. 定数を 3120 倍して、いちばん近い整数に着地させます。それが一つ目の桁です。
2. 着地しきれなかった残りを 3120 倍して、いちばん近い整数に着地させます。それが次の桁です。二つ目からの桁は、−1560〜+1559 に収まります。
3. 2 を繰り返します。

3120 倍は「3120 回足す」、いちばん近い整数は「倍々の梯子で割り、残りが半分以上なら一つ上へ」です。

```python:code/b13_constants.py
def nearest_div(x: int, m: int) -> Tuple[int, int]:
    """x ÷ m のいちばん近い整数 q と、残り x − q·m（−m/2 … m/2）。"""
    neg = x < 0
    if neg:
        x = -x
    q = ladder_div(x, m)
    r = x + -(q * m)
    if r + r >= m:          # 半分以上残っていたら一つ上へ
        q += 1
        r += -m
    return (-q, -r) if neg else (q, r)


def expand3120(value: int, terms: int) -> Tuple[List[int], int]:
    """目盛りの値を 3120 の平衡展開に。戻り値（桁の並び, 最後の残り）。"""

    r = value
```

## 13.4 角としての π は割り切れている

長さとしての π は、3120 の目盛りで読んでも桁が終わりません。

一方で、角としての π（半周）は、3120 の輪の上では **1560 番地** です。1560 + 1560 = 3120 で、ぴたりと割り切れています。

第3章からこの本は、向きを番地で持ってきました。番地で持つかぎり、π は無限に続く数ではなく、輪のちょうど半分の位置です。π が無限に続くのは、輪の外側の長さを、まっすぐな物差しで測ろうとしたときです。

## 13.8 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。

- いちばん近い整数を桁にとる展開は、桁の範囲を −B/2〜B/2 にとる「平衡 B 進展開」（ここでは B = 3120）です。
- π・e・ln 2・φ・√5 は、どれも有理数ではないので、どの基数で展開しても桁は終わりません。
- 確かめた範囲 [計算]：
  - 五つの定数の 3120 の桁を、観察者側の 80 桁の小数計算で同じ手順を踏んだものと比べました。10 段まで全部一致しました。11 段目は、π・e・ln 2 で目盛り（10⁴⁰）の細かさが足りなくなり、一致しませんでした。そのため本文は 10 段までにしています。
  - π の最初の 5 桁（9802, −720, −1475, −1354, −367）は、以前の記事のコード（`b13_pi.py`）の結果と一致しました。
  - √5 の桁と φ の桁の関係は、上の 10 段から読んだ観察です。

## 13.9 この章のまとめ

五つの定数を、3120 の目盛りで読み直しました。

- 3120 倍して、いちばん近い目盛りに着地させることを繰り返すと、定数が 3120 の桁の並びになります。
- φ の一つ目の桁 5048 は、B13 の位相ライブラリの定数と同じです。√5 の桁は、φ の桁から足し算と繰り上がりで出ます。
- 長さとしての π は桁が終わりませんが、角としての π は 1560 番地で、輪のちょうど半分です。

- 残渣（引き切れずに残ったもの）は、一周を n 等分したとき（第3章）、割り算の余り（第4章）、目盛りの最後の桁（第10〜13章）に出てきました。
