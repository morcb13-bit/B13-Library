# 序章　足し算だけで書くという約束

この本は、B13 で使ってきた計算の道具を一冊にまとめたものです。

四則演算、指数と対数、三角関数、微分と積分。これらが足し算に帰着することは、2026年2月の論文「Nature Knows Only Addition」で書きました。この本は同じ題を引き継ぎます。論文では主張として書いたことを、この本では**走るコード**と**動く図**にして、実演として並べます。

## 約束

この本のコードは、次の三つだけで書きます。

1. **整数**：浮動小数は使いません。
2. **足し算**：引き算は「符号を裏返して足す」、掛け算は「足すのを繰り返す」として書きます。
3. **比べる**：どちらが大きいか、端を越えたか、の判定です。

割り算・剰余・べき乗が出てくる場所は、**観察者側の読み**（10進に戻して人が確かめるための表示）に限ります。コードの中でも、その部分にはそう書いておきます。

## 各章の並び

どの章も同じ順で書きます。

1. **B13 の言葉で**：その演算が担体の上で何をしているか。
2. **動く図**：HTML 一枚の図です。ページの中でそのまま動きます。
3. **コード**：`code/` に置いた Python の該当部分です。
4. **実行例**：コードを走らせて出た数をそのまま載せます。
5. **在処**：リポジトリのどこに元の道具があるか。

既存の数学の名前は、観察者側の整理として章の後ろにまとめます。
