# 第11章　三角関数：三角波の位相、虚数を使わない回転

## 11.1 回すことは、番地を足すこと

第3章で、向きは 3120 の番地として持ちました。回すことは、番地を足すことでした。

三角関数は、回したときの **影** を読むものです。向きそのものは番地で済んでいるので、この章で作るのは「その番地の影はどれだけか」という読みです。読み方を二つ作ります。

| 読み方 | 作り方 | 精度 |
|---|---|---|
| 三角波 | 番地から 0 までの道のりを数えるだけ | 形は合うが、値はずれる |
| 組で回す | 一番地ぶんの cos と sin を一度作り、整数の組を回す | 目盛りの 34 桁以上 |

## 11.2 三角波：道のりを数える

番地 p から 0 番地までの、輪の上の近い方の道のりを d とします。三角波は 780 − d です。

```python:code/b13_trig.py
def tri_cos(p: int) -> int:
    """番地 p の三角波（−780…+780）。0 番地で +780、半周で −780。"""
    ...
    d = p if p <= HALF else BASE + -p
    return QUARTER + -d
```

0 番地で +780、四分の一周（780 番地）で 0、半周（1560 番地）で −780 です。cos と同じ所で山・谷・0 を通りますが、途中は直線です。これは B13 の位相ライブラリにもとからある波です。

足し算と比べることだけでできるので、向きの大まかな読みにはこれで足ります。

## 11.3 一番地ぶんの cos と sin

本物の影の値を作るには、一番地ぶんの角の cos と sin が一組あれば足ります。

一番地は、一周の 3120 分の 1 です。半径 1 の円で測ると、角の大きさは 2π ÷ 3120 です。π は次の式で、割って足すだけで作れます（第13章でもう一度扱います）。

```
π ÷ 4 = 4 × arctan(1/5) − arctan(1/239)
arctan(1/m) = 1/m − 1/(3m³) + 1/(5m⁵) − …
```

角 θ ができたら、cos と sin は第10章と同じ形の級数です。項を作るたびに θ² を掛けて、二つの数で割ります。

```
cos：項 ← −項 × θ² ÷ ((2k − 1)(2k))
sin：項 ← −項 × θ² ÷ ((2k)(2k + 1))
```

```python:code/b13_trig.py
def cos_sin_rad(t: int) -> Tuple[int, int]:
    """角 t（目盛り、ラジアン）の cos と sin を級数で。"""
    t2 = fmul(t, t)
    c_term, c, k = S, S, 1
    while c_term:
        c_term = -sdiv(fmul(c_term, t2), (2 * k - 1) * (2 * k))
        c += c_term
        k += 1
    ...
```

## 11.4 表は二つ前から作る

一番地ぶんの cos（c(1) と書きます）があれば、どの番地の cos も、二つ前の値から作れます。

```
c(k + 1) = 2 × c(1) × c(k) − c(k − 1)
```

一歩ごとに掛け算は一回だけで、あとは足し算と引き算です。フィボナッチ数の作り方（前の二つを足す）と同じ形をしています。

```python:code/b13_trig.py
def cos_table(n: int = BASE) -> List[int]:
    """番地 0…n の cos。c(k+1) = 2·c(1)·c(k) − c(k−1)。"""
    out = [S, C1]
    two_c1 = C1 + C1
    for _ in range(n - 1):
        out.append(fmul(two_c1, out[-1]) + -out[-2])
    return out
```

この表を 3120 番地まで作り、知っている値と比べました。

| 番地 | 角 | 知っている値 | 一致した桁（目盛り 40 桁のうち） |
|---:|---|---|---:|
| 312 | 36° | φ ÷ 2 | 35 |
| 520 | 60° | 1 ÷ 2 | 34 |
| 624 | 72° | (φ − 1) ÷ 2 | 34 |
| 780 | 90° | 0 | 34 |
| 1560 | 180° | −1 | 36 |
| 3120 | 一周 | 1 | 36 |

36° と 72° の cos は、φ の世界の数（第2章・第8章）です。3120 の表は、五角形の角で φ の値にぴたりと着地します。

## 11.5 虚数を使わない回転

矢を、整数の組 (x, y) で持ちます。一番地回すたびに、次のように置き換えます。

```
(x, y) → (c·x − s·y,  s·x + c·y)
```

c と s は、一番地ぶんの cos と sin の目盛りです。組の二つの整数を置き換えるだけで、虚数 i は出てきません。

```python:code/b13_trig.py
def rotate(v: Tuple[int, int], c: int, s: int) -> Tuple[int, int]:
    x, y = v
    return (fmul(c, x) + -fmul(s, y), fmul(s, x) + fmul(c, y))


def quarter_turn(v: Tuple[int, int]) -> Tuple[int, int]:
    """780 番地（四分の一周）は入れ替えと裏返しだけ（第5章）。"""
    return (-v[1], v[0])
```

(1, 0) から一番地ずつ 3120 回回すと、(1, 0) に戻ってきます。目盛りの整数で見た出発点との差は (1107, −2059) で、10⁴⁰ の目盛りの中の残渣です。

四分の一周（780 番地）だけは、c も s も要りません。第5章の振幅と同じく、入れ替えと裏返しだけで回り、4 回でぴたり元に戻ります。

## 11.9 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。

- (x, y) → (c·x − s·y, s·x + c·y) は、回転行列を掛けることです。複素数 x + yi に cos θ + i sin θ を掛けるのと同じ計算ですが、組のまま書けば i は要りません。
- c(k + 1) = 2c(1)c(k) − c(k − 1) は、チェビシェフ多項式の漸化式（cos の倍角の公式を一歩ずつ使うもの）です。
- π ÷ 4 = 4 arctan(1/5) − arctan(1/239) は、マチンの公式（1706年）です。
- cos 36° = φ/2、cos 72° = (φ − 1)/2 は、正五角形の対角線と辺の比が φ であることから出ます。
- 確かめた範囲 [計算]：
  - π を観察者側の 50 桁の値と比べ、10⁻³⁸ より小さい差で一致しました。
  - cos の表の 0〜3120 番地すべてを、観察者側の浮動小数の cos と比べました。差は 10⁻¹⁵（浮動小数そのものの精度）より小さく収まりました。
  - φ の値との比較は、第9章の開平で作った √5 を使いました。

## 11.10 この章のまとめ

三角関数は、番地の影を読むことです。

- 三角波は、番地から 0 までの道のりを数えるだけで作れます。形は cos と同じ所を通りますが、値はずれます。
- 一番地ぶんの cos と sin を一度作れば、表は二つ前の値から作れ、矢は整数の組のまま回せます。虚数は要りません。
- 五角形の角（624 番地）で、cos は φ の世界の値にぴたりと着地します。
- 四分の一周は、入れ替えと裏返しだけで回ります。

次の章では、円の代わりに双曲線の上を回します。第8章の φ 倍が、その一歩になります。
