# 第1章　平衡13進と平衡5進

## 1.1 0 を真ん中に置く

ふつうの13進では、桁は 0〜12 です。0 が端にあります。

平衡13進では、桁を **−6〜+6** に並べます。0 が真ん中にあり、正と負が左右に同じ数だけ並びます。平衡5進なら **−2〜+2** です。

| 基数 N | 桁の範囲 | 桁の数 |
|---|---|---|
| 13 | −6 … +6 | 13 |
| 5 | −2 … +2 | 5 |

桁の上限 h は、`h + h + 1 = N` を満たす数です。コードでも、この足し算で h を求めます。

13 は番地の基数、5 は五芒星の桁です。どちらも奇数なので、0 を真ん中に置けます。

## 1.3 足す

桁ごとに足して、はみ出したら N を一つ引き、上の桁へ ±1 を送ります。

```python:code/b13_balanced.py
def add(a: Digits, b: Digits, N: int) -> Digits:
    """桁ごとに足し、はみ出したら N を一つ引いて上へ ±1 を送る。"""
    h = half(N)
    out: Digits = []
    carry = 0
    i = 0
    while i < len(a) or i < len(b) or carry != 0:
        s = carry
        if i < len(a):
            s += a[i]
        if i < len(b):
            s += b[i]
        carry = 0
        if s > h:
            s += -N
            carry = 1
        elif s < -h:
            s += N
            carry = -1
        out.append(s)
        i += 1
    return trim(out) if out else [0]
```

桁の並びは下の桁から持ちます（`a[0]` が 1 の桁）。上へ送るのは +1 か −1 のどちらかです。0〜12 の13進では、上へ送るのは +1 だけでした。平衡桁では、送るものにも符号があります。

## 1.4 符号を裏返す

負の数は、各桁の符号を裏返すだけで作れます。

```python:code/b13_balanced.py
def neg(a: Digits) -> Digits:
    """符号の裏返し：各桁の符号を裏返すだけ。繰り上がりは起きない。"""
    return [-d for d in a]


def sub(a: Digits, b: Digits, N: int) -> Digits:
    """引き算＝裏返したものを足す。"""
    return add(a, neg(b), N)
```

符号のための桁は要りません。引き算のための別の回路も要りません。引き算は、裏返したものを足すことです。

## 1.5 符号を読む・丸める

平衡桁には、ほかにも性質が二つあります。

**符号は一番上の桁が決めます。** 0 でない一番上の桁が正なら、数全体も正です。下の桁をすべて足しても、一番上の桁一つ分には届かないからです。

```python:code/b13_balanced.py
def sign(a: Digits) -> int:
    """符号は一番上の 0 でない桁の符号そのもの。"""
    for d in reversed(a):
        if d > 0:
            return 1
        if d < 0:
            return -1
    return 0
```

**下の桁を捨てると、一番近い値に丸まります。** 切り捨てと四捨五入が同じ操作になります。捨てた部分は、いつも半目盛り以内に収まっているからです。

```python:code/b13_balanced.py
def cut(a: Digits, k: int) -> Digits:
    """下の k 桁を捨てる。平衡桁ではこれがそのまま「一番近い値への丸め」になる。"""
    return trim(a[k:]) if len(a) > k else [0]
```

## 1.6 10進から入る

人が書く 10進の数は、足し算だけで平衡桁に入れます。10進の桁を上から読み、「いまの値を 10 回足したもの」に次の桁を足します。

```python:code/b13_balanced.py
def times_small(a: Digits, k: int, N: int) -> Digits:
    """小さな非負整数 k 倍 ＝ a を k 回足す。"""
    out: Digits = [0]
    for _ in range(k):
        out = add(out, a, N)
    return out


def from_decimal(text: str, N: int) -> Digits:
    """10進の文字列から入る。x ← x を10回足したもの ＋ 次の桁（足し算だけ）。"""
    s = text.strip()
    negative = s.startswith("-")
    if negative:
        s = s[1:]
    x: Digits = [0]
    for ch in s:
        x = times_small(x, 10, N)
        for _ in range(ord(ch) - ord("0")):    # 1 桁ぶん（0〜9）は 1 をその回数足す
            x = add(x, [1], N)
    return neg(x) if negative else x
```

10進の 1 桁（0〜9）は、1 をその回数だけ足して入れます。平衡5進の桁は ±2 までなので、8 や 9 を一度に足すことはしません。

表示は対応表と同じ表記です。

```
== 平衡13進（桁 −6…+6）
(2026)₁₀ → (+1,−1,0,−2)₁₃
(−2026)₁₀ → (−1,+1,0,+2)₁₃
(+1,−1,0,−2)₁₃ + (−1,+1,0,+2)₁₃ → (0)₁₃
(2026)₁₀ − (1000)₁₀ → (+6,+1,−1)₁₃ = (1026)₁₀
符号： 1 -1 0
下1桁を捨てる → (+1,−1,0)₁₃ の 13^1 倍 = (2028)₁₀
下2桁を捨てる → (+1,−1)₁₃ の 13^2 倍 = (2028)₁₀

== 平衡5進（桁 −2…+2）
(2026)₁₀ → (+1,−2,+1,+1,0,+1)₅
(−2026)₁₀ → (−1,+2,−1,−1,0,−1)₅
(+1,−2,+1,+1,0,+1)₅ + (−1,+2,−1,−1,0,−1)₅ → (0)₅
(2026)₁₀ − (1000)₁₀ → (+2,−2,+1,0,+1)₅ = (1026)₁₀
符号： 1 -1 0
下1桁を捨てる → (+1,−2,+1,+1,0)₅ の 5^1 倍 = (2025)₁₀
下2桁を捨てる → (+1,−2,+1,+1)₅ の 5^2 倍 = (2025)₁₀
```

読み方です。

- **(2026)₁₀** は、(+1,−1,0,−2)₁₃、(+1,−2,+1,+1,0,+1)₅ です。
- **(−2026)₁₀** は、どちらも各桁の符号が裏返っただけの並びです。
- **(2026)₁₀ − (1000)₁₀** は、裏返した (1000)₁₀ を足した結果で、(1026)₁₀ になります。
- **下の桁を捨てる**と、平衡13進では 13 の倍数・169 の倍数のうち (2026)₁₀ に一番近い (2028)₁₀ に着地します。平衡5進では 5 の倍数・25 の倍数のうち一番近い (2025)₁₀ に着地します。

図の文字盤で「2026 へ」を押すと、同じ並びが針で出ます。

`(…)₁₀` と `13^k 倍` の部分は、観察者側の読み（10進への表示）です。判定そのものには使っていません。

## 1.9 観察者側の整理

既存の数学の名前との対応は次のとおりです。いずれも Claude の知識によるもので、この本では検算していません。

- 平衡3進（桁 −1, 0, +1）は、平衡N進のうち一番小さい場合です。クヌースが『The Art of Computer Programming』第2巻で取り上げています。1958年のソ連の計算機「セトゥニ」は、平衡3進で動いていました。
- 「下の桁を捨てると一番近い値に丸まる」「符号のための桁が要らない」という性質は、平衡3進の長所として昔から知られています。基数が奇数なら、平衡N進でも同じことが成り立ちます。

## 1.10 この章のまとめ

平衡桁では、0 が真ん中にあります。そのため次の四つが、足し算と比べることだけで済みます。

- 負の数は、各桁の符号を裏返すだけで作れます。
- 引き算は、裏返したものを足すことです。
- 符号は、一番上の桁を見れば分かります。
- 丸めは、下の桁を捨てることです。
