# 第7章　平方剰余・ピサノ周期・篩

## 7.1 輪の上で数を並べる

第6章で、輪の上の算術がそろいました。この章では、その輪の上に三つの並びを作ります。

| 並び | 作り方 | 見えるもの |
|---|---|---|
| 平方 | 奇数 1, 3, 5, … を順に足す | どの数が平方になれるか |
| フィボナッチ数 | 前の二つを足す | 一周の長さ（ピサノ周期） |
| 篩 | 残った数ずつ跳ぶ | 素数 |

三つとも、足し算と「輪を越えたら引く」だけで作ります。

## 7.2 平方剰余：奇数を足して平方を作る

1, 4, 9, 16, … は、奇数 1, 3, 5, 7, … を順に足したものです。掛け算をしなくても、平方は足し算で作れます。

```python:code/b13_residue.py
def squares_mod(p: int) -> List[int]:
    """k = 0, 1, …, p−1 の k² を p の輪で。次の平方は、今の平方に次の奇数を足したもの。"""
    out = [0]
    sq, odd = 0, 1
    for _ in range(p - 1):
        sq = sq + odd
        while sq >= p:
            sq += -p
        out.append(sq)
        odd = odd + 2
        while odd >= p:
            odd += -p
    return out
```

13 の輪で平方になれる数（0 を除く）は、次の 6 個です。

| 13 の輪の平方 | 1 | 3 | 4 | 9 | 10 | 12 |
|---|---|---|---|---|---|---|
| 計算尺の目盛り（第5章） | 0 | 4 | 2 | 8 | 10 | 6 |

どれも **偶数の目盛り** にあります。平方は目盛りを 2 倍することなので、偶数の目盛りにしか着地しません。

5 は目盛り 9（奇数）にあるので、13 の輪では平方になれません。13 の輪の中に √5 はありません。φ = (1 + √5) ÷ 2 も、13 の輪の中にはありません。

## 7.3 5 が平方になる輪、ならない輪

素数 p の輪ごとに、5 が平方になれるかを調べます。p を 5 で割った余りで並べると、きれいに分かれます。

| p を 5 で割った余り | 5 は平方か | 例 |
|---|---|---|
| 1 | なれる | 11, 31, 41, 61, 71, … |
| 4 | なれる | 19, 29, 59, 79, 89, … |
| 2 | なれない | 7, 17, 37, 47, 67, … |
| 3 | なれない | 3, 13, 23, 43, 53, … |

13 は「なれない」側にあります。√5 も φ も持たない輪です。

## 7.4 ピサノ周期：フィボナッチ数の輪

フィボナッチ数を、m の輪の上で作ります。前の二つを足して、m を越えたら m を引きます。(0, 1) に戻ったら一周です。その歩数を **ピサノ周期** と呼びます。

```python:code/b13_residue.py
def pisano(m: int) -> int:
    """フィボナッチ数を m の輪で足していき、(0, 1) に戻るまでの歩数。"""
    if m == 1:
        return 1
    a, b, n = 0, 1, 0
    while True:
        a, b = b, wrap(a + b, m)
        n += 1
        if a == 0 and b == 1:
            return n
```

13 の輪のフィボナッチ数は、28 歩で一周します。

```
0 1 1 2 3 5 8 │ 0 8 8 3 11 1 12 │ 0 12 12 11 10 8 5 │ 0 5 5 10 2 12 1 │ 0 1
```

7 歩ごとに 0 に着地します。F₇ = 13 だからです。0 で区切ると、4 つの組に分かれます。

各組は、前の組を 8 倍したものです。組の先頭は 1, 8, 12, 5 と進み、これは第5章の計算尺で「目盛り 0, 3, 6, 9」の組（H）です。8 は、二回掛けると −1 になる数（第6章）でした。13 の輪のフィボナッチ数は、7 歩ごとに四分の一周ずつ回り、4 回で元に戻ります。

28 = 7 × 4 です。

5 が平方になれる輪（11, 29, 31, …）では、一周の長さが p − 1 を割り切ります。なれない輪（13, …）では、2 × (p + 1) を割り切ります。

## 7.6 篩：跳んで印をつける

2 から順に見て、まだ印のない数に来たら、その数ずつ跳んで、先の数に印をつけます。跳ぶのは足し算です。最後まで印のつかなかった数が素数です。

```python:code/b13_residue.py
def sieve(N: int) -> List[int]:
    """2 から N まで。残った数から順に、その数ずつ跳んで印をつける。"""
    hit = [False] * (N + 1)
    primes = []
    for p in range(2, N + 1):
        if hit[p]:
            continue
        primes.append(p)
        q = p + p
        while q <= N:
            hit[q] = True
            q += p
    return primes
```

[監督] 素数は「篩から落ちる数」ではなく、篩そのものである。篩の材料は 2 と 3 だけである。

2 と 3 で跳んだ後に残る数は、次のとおりです。

```
1 5 7 11 13 17 19 23 25 29 31 35 37 41 43 47 49 53 55 59 …
```

6 の列に並べると、残りは「6 で割って 1 余る列」と「5 余る列」の 2 本だけです。この先の素数は、どれもこの 2 本の列の上にあります。

## 7.7 動く図：跳んで印をつける篩

数の表を、選んだ列の数で折り返します。残った数から順に、その数ずつ跳んで印をつけます。

## 7.10 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。

- 平方になれる数を「平方剰余」と呼びます。5 が p の輪で平方剰余になるのは p を 5 で割った余りが 1 か 4 のときだ、というのは平方剰余の相互法則から出ます。
- フィボナッチ数の一の位が 60 で繰り返すことは、ラグランジュ（1774年）が記しています。ピサノ周期が p − 1 または 2(p + 1) を割り切ることは、D. D. ウォールの論文「Fibonacci series modulo m」（1960年）でまとめられています。F₇ = 13 のように m の倍数に初めて着地する番号を「出現位置」と呼びます。
- 跳んで印をつける篩は、エラトステネスの篩です。2・3・5 の跳びの後に残る列だけを見る方法は「車輪」と呼ばれます。
- 確かめた範囲 [計算]：
  - 平方剰余を、400 までのすべての奇素数で確かめました。
  - 5 が平方剰余になる条件（p を 5 で割った余りが 1 か 4）を、2000 までの素数で確かめました。
  - ピサノ周期を m = 2〜499 で確かめ、p − 1 または 2(p + 1) を割り切ることを 2000 までの素数で確かめました。
  - 篩を 10000 まで確かめました。
  - 13 の輪のフィボナッチ数が 7 歩ずつ 4 組に分かれ、各組が前の組の 8 倍になっていることは、上の 28 項から読んだものです。

## 7.11 この章のまとめ

輪の上に三つの並びを、足し算だけで作りました。

- 平方は奇数を順に足して作れます。13 の輪では、平方は計算尺の偶数の目盛りにしか着地せず、5 は平方になれません。
- 5 が平方になれるかどうかは、p を 5 で割った余りで決まります。
- 13 の輪のフィボナッチ数は、7 歩ごとに 0 に着地し、そのたびに四分の一周回って、28 歩で一周します。
- 篩は、残った数ずつ跳ぶだけです。2 と 3 で跳んだ後、残りは 6 の列の 2 本に並びます。

ここが本の折り返しです。第2部の残りの2章では、ここまでの輪の算術を φ の世界へ持ち込みます。次の章では、整数の組 a + bφ のノルム・単数・φ 倍を扱います。
