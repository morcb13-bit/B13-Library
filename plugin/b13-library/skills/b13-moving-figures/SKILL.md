## 作るときの決まり

1. **一枚の HTML** に、マークアップ・CSS・スクリプトをすべて入れる。外部のライブラリを読み込まない（CodePen にそのまま貼るため）。
2. **一図一ファイル**で渡す。zip にまとめない。アーティファクトとして公開できる場ではアーティファクトにも出し、HTML ファイルも渡す（両方で管理する）。
3. **図の中の計算も整数と足し算だけ**。座標を画面に置くための最後の換算だけ浮動小数を使ってよく、そこには「観察者側の表示」とコメントを書く。図に出す数は b13-library のスクリプトの出力と一致させる。
4. **既定で再生**する。止める・一歩進める・速さを変える操作を付ける。
5. 色は既存の図と同じく CSS 変数（--bg, --panel など）で持つ。新しい図はまず assets の近い図を開いて作りを写す。
6. 図の題・説明は日本語。帰属（[計算]・[見立て]）が要る数は図の外の本文側に書く。

## 手順

1. 頼まれた図に近いものを上の表から選び、assets のファイルを読む。
2. 既存の図で足りれば、そのファイルを渡す。
3. 作り直す・新しく作るときは、計算部分を b13-library のコードと同じ手順（足し算だけ）で JavaScript に写し、出る数をスクリプトの実行例と突き合わせてから渡す。
