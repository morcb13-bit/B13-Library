差分と和

隣どうしを引くと差分、ここまでを足すと和です。差分を何段も取ると、n² は 2 段目で 2 に、n³ は 3 段目で 6 に着地します。0〜1 の x² の下を n 本の柱で数えると、n³ と「柱の和の 3 倍」との差は、五角数 1, 5, 12, 22, … になります。

0〜1 の x² の下を柱で数える

n = 1　n³ = 1
低い柱の和 L = 0　高い柱の和 H = 1
n³ − 3L = 1　（五角数）
3H − n³ = 2　右の点の数 = 1

柱の幅は 1/n です。高さを n² 倍すると、低い柱は 0², 1², …, (n−1)²、高い柱は 1², 2², …, n² の整数になり、面積は「和 ÷ n³」です。3L は n³ より五角数だけ小さく、3H は n³ より別の五角数だけ大きくなります。曲線と柱の線は作図用の小数で描いています。右の図は、五角形を一つの角を共有して大きくしていったときの点の数です。
