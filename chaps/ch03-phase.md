# 第3章　BASE=3120 の位相

## 3.1 一周を 3120 の番地に刻む

向き（位相）は、一周を 3120 の番地に刻んで持ちます。番地は 0 から 3119 まで。一周すると 0 に戻ります。

```
3120 = 2⁴ × 3 × 5 × 13
     = 60 × 52
```

60 は切頂二十面体の頂点の数、52 は 13 × 4 です。五角形の 5、番地の 13、四分の一周の 4 が、どれも 3120 にそのまま入っています。

位相の操作は二つだけです。

| 操作 | 書き方 | ひとこと |
|---|---|---|
| 足す | 番地を足し、3120 を越えたら 3120 を一つ引く | 回す |
| 裏返す | 3120 から引く（0 は 0 のまま） | 鏡に映す |

角度の表は要りません。番地の足し算がそのまま回転です。

## 3.2 ちょうど一周に着地する歩幅

0 から同じ歩幅を足し続けると、いつか 0 に戻ります。何歩で戻るかは、歩幅で決まります。

歩幅を足していって、3120 にぴたりと当たる歩幅を数えると、40 通りあります（3.7 節）。この歩幅なら、正多角形の頂点が番地の上に誤差なく着地します。

| 歩幅 | 歩数 | ひとこと |
|---:|---:|---|
| (1040)₃₁₂₀ | 3 | 三角形 |
| (780)₃₁₂₀ | 4 | 四分の一周 |
| (624)₃₁₂₀ | 5 | 五角形（五芒星の頂点） |
| (260)₃₁₂₀ | 12 | 十二等分 |
| (240)₃₁₂₀ | 13 | 十三等分（番地の一歩） |
| (52)₃₁₂₀ | 60 | 切頂二十面体の頂点の数 |
| (26)₃₁₂₀ | 120 | 3120 で刻める一番細かい「度」（3°） |
| (1000)₃₁₂₀ | 78 | 3120 にぴたり当たらない歩幅は、何周かしてから戻る |
| (1201)₃₁₂₀ | 3120 | すべての番地を一度ずつ通ってから戻る |

## 3.4 回す・裏返す

```python:code/b13_phase.py
BASE = 3120


def padd(a: int, b: int) -> int:
    s = a + b
    if s >= BASE:
        s += -BASE
    return s


def pneg(a: int) -> int:
    return 0 if a == 0 else BASE + -a


def orbit(step: int) -> List[int]:
    """0 から step ずつ足し、0 に戻るまでの番地の列。"""
    out = [0]
    p = padd(0, step)
    while p != 0:
        out.append(p)
        p = padd(p, step)
    return out
```

「一周したか」は、番地が 0 と等しいかどうかで判定します。等号で判定できるので、許容誤差は要りません。

## 3.5 細かく刻む：番地の下にもう一桁

3120 の番地より細かい向きが欲しいときは、番地の下にもう一桁つなぎます。下の桁も 3120 刻みで、3120 を越えたら上の桁へ 1 を送ります。第1章の繰り上がりと同じ仕組みです。

```python:code/b13_phase.py
def dadd(a: Digits, b: Digits) -> Digits:
    """多桁の位相を足す。下の桁から繰り上がりを送り、一番上は一周で 0 に戻る。"""
    out = [0] * len(a)
    carry = 0
    for i in range(len(a) - 1, -1, -1):
        s = a[i] + b[i] + carry
        carry = 0
        if s >= BASE:
            s += -BASE
            carry = 1
        out[i] = s
    return out
```

桁を一つ増やすごとに、刻みは 3120 分の 1 になります。

## 3.6 一周を n 等分する：残渣

一周を n 等分する歩幅は、筆算で桁ごとに求めます。一周を 3120 倍して、n を引けるだけ引きます。引いた回数がその桁、引き切れずに残ったものが **残渣** です。

```python:code/b13_phase.py
def split_turn(n: int, ndig: int) -> Tuple[Digits, int]:
    """一周を n 等分する歩幅を ndig 桁まで筆算で求める（引けるだけ引く）。
    戻り値：(歩幅の桁, 残渣)。残渣が 0 なら n 歩でちょうど一周する。"""
    digits: Digits = []
    rem = 1                     # 「一周」が 1 つ
    for _ in range(ndig):
        # rem を 3120 倍する（3120 回足す）
        r = 0
        for _ in range(BASE):
            r += rem
        q = 0
        while r >= n:           # 引けるだけ引く
            r += -n
            q += 1
        digits.append(q)
        rem = r
    return digits, rem
```

- **残渣が 0**：n 歩でちょうど 0 に着地します。n = 5, 13, 16 がこの形です。
- **残渣が残る**：n 歩では、0 の手前で止まります。n = 7 の歩幅を 7 歩足すと (3119,3116)₃₁₂₀ で、0 まで最後の桁で 4 足りません。この 4 が残渣です。

3120 の材料は 2・3・5・13 です。7 や 11 は材料に入っていないので、桁をいくら増やしても残渣は 0 になりません。7 や 11 は、3120 の輪の上では、いつも少しずれた所に着地します。

## 3.9 観察者側の整理

既存の数学の名前との対応です。Claude の知識によるもので、この本では検算していません（3.7 節の数は計算で出したものです）。

- 歩幅 s で何歩で一周するかは、3120 を s と 3120 の最大公約数で割った数です。ぴたり当たる歩幅 40 通りは、3120 の約数です。
- 歩幅 1201 がすべての番地を通るのは、1201 と 3120 が互いに素だからです。
- 360 を一周とする度は、2³ × 3² × 5 でできています。3120 と共通の材料は 2・3・5 なので、3 度刻み（120 等分）までは両方で誤差なく書けます。
- 一周を n 等分して残渣が 0 になるのは、n の素因数が 2・3・5・13 だけのときです。10 進の小数で 1/3 が割り切れないのと同じ仕組みです。

## 3.10 この章のまとめ

向きは、3120 の番地として持ちます。

- 回すのは番地の足し算、鏡に映すのは 3120 から引くことです。
- 一周したかどうかは、番地が 0 と等しいかで判定できます。
- 2・3・5・13 でできた等分は誤差なく着地します。それ以外は、桁をいくら増やしても残渣が残ります。
- 細かい向きが要るときは、下に桁をつないで繰り上がりで送ります。
