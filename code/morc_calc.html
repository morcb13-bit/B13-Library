この電卓のしくみ

数はすべて「整数 ÷ 整数」の分数のまま持ちます。たとえば 0.1 は 1/10、0.2 は 1/5 です。0.1 + 0.2 を足すと 3/10 になるので、答えはちょうど 0.3 です（浮動小数で計算する多くの電卓やプログラムでは 0.30000000000000004 になります）。

中でしている操作は、足すことと大小を比べることだけです。画面の回数は答えの分数を出すまでの分で、10 進の小数や平衡進数に書き換える分は入れていません。小数は、負の数も 0 の向きに切り捨てます。引き算は符号を返して足し、掛け算は自分自身を足した倍々のはしごから必要な段を拾って足し、割り算は割る数のはしごを上の段から引けるだけ引きます。分数は最後に互除法で約分します。

平衡進数の欄には、上に出した答えと同じ数を、平衡3進（−1・0・+1）と平衡13進（−6〜+6）で書きます。小数のある答えは、平衡進数にも小数点を付け、指定の桁数と同じ細かさまで書きます。

√2 や π、EXP・LN・SIN のように終わりのない数は、指定した桁数より 12 桁多く整数で計算してから打ち切り、「近似」の印を付けます。式の中に近似が一つでも入ると、答えも近似になります。分数で表せる答えには「正確」の印が付き、小数が繰り返すときは繰り返しの部分を（ ）で示します。
