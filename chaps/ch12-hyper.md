# 第12章　双曲関数と双曲回転

## 12.1 符号を一つ裏返す

第11章の cos と sin は、項を作るたびに符号を裏返す級数でした。符号を裏返さないと、cosh と sinh（双曲関数）になります。

| | 項の作り方 | 変わらない量 |
|---|---|---|
| cos, sin | 項 ← **−**項 × t² ÷ (…) | cos² + sin² = 1 |
| cosh, sinh | 項 ← 項 × t² ÷ (…) | cosh² − sinh² = 1 |

回し方も、符号が一つ違うだけです。

| | 一歩 | 変わらない量 | 点が動く線 |
|---|---|---|---|
| 円の回転 | (x, y) → (c·x **−** s·y, s·x + c·y) | x² + y² | 円 |
| 双曲回転 | (x, y) → (C·x **+** S·y, S·x + C·y) | x² − y² | 双曲線 |

```python:code/b13_hyper.py
def cosh_sinh(t: int) -> Pair:
    t2 = fmul(t, t)
    c_term, c, k = S, S, 1
    while c_term:
        c_term = sdiv(fmul(c_term, t2), (2 * k - 1) * (2 * k))     # 符号を裏返さない
        c += c_term
        k += 1
    ...


def boost(v: Pair, C: int, Sh: int) -> Pair:
    x, y = v
    return (fmul(C, x) + fmul(Sh, y), fmul(Sh, x) + fmul(C, y))
```

## 12.2 一歩を重ねると、t が足される

t = 0.2 の一歩を 5 回重ねると、t = 1 の一歩と同じ所に着きます（実行例）。円の回転で角が足されるのと同じように、双曲回転では t が足されます。双曲回転の t を、**ラピディティ** と呼びます。

## 12.3 整数のままの双曲回転：φ² を掛ける

円の回転は、一番地ぶんの cos と sin を目盛りで作る必要がありました（第11章）。双曲回転には、整数のまま回せる一歩があります。Z[φ] で φ² を掛けることです。

```
φ² を掛ける：(a, b) → (a + b, a + 2b)
φ² で割る：  (a, b) → (2a − b, b − a)
```

足し算だけで、ノルム a² + ab − b² が変わりません（第8章）。円の回転で x² + y² が変わらないのと同じ立場です。

```python:code/b13_hyper.py
def phi2(u: Pair) -> Pair:
    """φ² を掛ける：(a, b) → (a + b, a + 2b)。"""
    a, b = u
    return (a + b, a + b + b)
```

| 一歩ずつ | 組 | ノルム |
|---|---|---:|
| φ⁰ | (1, 0) | +1 |
| φ² | (1, 1) | +1 |
| φ⁴ | (2, 3) | +1 |
| φ⁶ | (5, 8) | +1 |
| φ⁸ | (13, 21) | +1 |
| 3 + φ | (3, 1) | +11 |
| × φ² | (4, 5) | +11 |
| × φ² | (9, 14) | +11 |
| ÷ φ² | (5, −2) | +11 |

この一歩の大きさ（ラピディティ）は ln φ² = 0.9624… で、cosh にあたる量は 3/2、sinh にあたる量は √5/2 です。3/2 は、組の動き (a, b) → (a + b, a + 2b) の対角の和 1 + 2 = 3 を 2 で割ったものです。整数の 3 が、双曲回転の大きさを決めています。

φ を一回だけ掛けると、ノルムの符号が裏返ります。点は向かい合う双曲線（ノルム −N）へ跳びます。第8章の図で青と赤を交互に跳んだのは、このためです。二回掛けて、同じ双曲線の上に戻ってきます。

## 12.4 置き方を変えると、双曲線がまっすぐ見える

Z[φ] の数 a + bφ を、横 u = a + bφ、縦 v = a + b(1 − φ) の位置に置きます（1 − φ は φ の共役）。

この置き方では、

- ノルムが u × v になります。ノルム N の点は、双曲線 u × v = N の上に並びます。
- 第8章の点線（ノルム 0）が、縦と横の軸になります。
- φ² を掛けると、u は φ² 倍、v は φ² 分の 1 になります。片方を伸ばし、もう片方を同じ割合で縮めるだけです。

双曲回転は、この置き方で見ると「伸ばして縮める」動きです。

## 12.6 ペル方程式も双曲回転

第9章のペル方程式 x² − n y² = 1 の解も、双曲回転を作ります。n = 2 なら、解 (3, 2) から

```
(x, y) → (3x + 4y, 2x + 3y)
```

が x² − 2y² を変えない一歩です。(1, 0) から始めると、(3, 2), (17, 12), (99, 70), … と、どれも x² − 2y² = 1 の上を進みます。第9章の √2 の近似分数のうち、一つおきのものです。

## 12.9 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。

- cosh t = (eᵗ + e⁻ᵗ)/2、sinh t = (eᵗ − e⁻ᵗ)/2 で、cos・sin とは級数の符号だけが違います。
- 双曲回転は、特殊相対性理論のローレンツ変換と同じ形をしています。t はラピディティで、速さそのものは足せませんが、ラピディティは足せます。
- u = a + bφ、v = a + bφ̄ と置くのは、Z[φ] を平面に埋め込む「ミンコフスキー埋め込み」です。この置き方で一方の軸へ射影すると、フィボナッチ鎖（一次元の準結晶）が出ます。
- 伸ばして縮める写像は「スクイーズ写像」と呼ばれます。
- 確かめた範囲 [計算]：上の実行例の数（t = 1/2, 1, 2 での不変量、t = 0.2 の 10 回、φ² の 6 歩、ペルの 6 歩）を確かめました。一般の形は、上の知識によるものです。

## 12.10 この章のまとめ

円と双曲線は、符号一つで入れ替わります。

- cosh と sinh は、cos と sin の級数で符号を裏返さないものです。双曲回転は x² − y² を変えません。
- 一歩を重ねると、t（ラピディティ）が足されます。
- Z[φ] では、φ² を掛けることが整数のままの双曲回転です。足し算だけで、ノルムが変わりません。
- 置き方を変えると、φ² 倍は「片方を伸ばし、もう片方を縮める」動きになります。
- ペル方程式の解も、整数の双曲回転を作ります。
