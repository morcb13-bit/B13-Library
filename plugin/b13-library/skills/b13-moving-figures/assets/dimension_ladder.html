点から600胞体の先へ

潰れていた軸が一本ずつ開く。逆転スイッチは φ と −1/φ を入れ替える

点を二つ並べると線分、線分の上に潰れていた五つの点が開くと五角形、その奥行きが開くと正二十面体、四本目の軸が開くと600胞体になる。最後に600胞体の φ 倍がもう一つ外へ育ち、240 個の点になる。各段で逆転スイッチを入れると、座標の φ がすべて −1/φ に置き換わり、五角形は五芒星へ、外側と内側の600胞体は入れ替わる。

いまの段

梯子

点と辺の数は、ページの中で座標を整数の組 (a, b) = a + bφ として作り、辺の長さの二乗が決まった値に等しい組を数えて出している。

座標はすべて a + bφ の形の整数の組で持ち、逆転は (a, b) → (a + b, −b) という整数の置き換えでしている。五角形だけは5本の整数の軸の上の点として持ち、逆転は軸の番号 k を 2k に送る置き換え。4次元から画面へ落とす回転と遠近、段の間の滑らかな動きは表示のためだけに実数で描いている。最後の段の「二つの600胞体」は、E₈ の240個を4次元に落とすと半径 1 と φ の600胞体が二つ出るという既知の対応に合わせて、ここでは600胞体とその φ 倍を直接並べたもの。E₈ から射影して数え直してはいない。
