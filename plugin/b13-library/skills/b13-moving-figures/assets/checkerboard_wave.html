市松の波動関数

右へ一歩・左へ一歩。曲がるたびに位相を四分の一回す。道の数を足し合わせるだけ

一点から出た粒を、斜め右下か斜め左下へ一段ずつ進める。向きを変えた回数で位相の番号 0, 1, 2, 3 が一つずつ進み、その番号ごとに道の数を数える。番号 0 から 2 を引いたものが実の側、1 から 3 を引いたものが虚の側になる。数えるのは整数だけで、色は位相の番号の釣り合いを表す。

実の側（0 − 2）虚の側（1 − 3）大きさ

位相の番号と色

番号 0 が赤、1 が黄緑、2 が青緑、3 が紫。途中の色は番号どうしの釣り合いで決まる。

つまみの意味

s はまっすぐ進む一歩につける重み。s を大きくすると曲がる道の割合が下がり、波は遅く、幅広く揺れる。s = 1 では光の速さの縁に張りついた鋭い模様になる。

これはファインマンの市松（1+1次元で道を数える方法）を整数のまま走らせたもの。曲がりが少ない側の極限がシュレーディンガー方程式の振る舞いに近づくことは知識として持っているが、この図では検算していない。数え上げは整数の足し算だけで、画面の色と曲線を出す段でだけ実数に直している。
