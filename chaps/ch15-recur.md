# 第15章　漸化式と畳み込み

## 15.1 二つ前から作る

この本には、前の二つから次を作る列が何度も出てきました。フィボナッチ数（第2章）、ペル方程式の解（第9章）、cos の表（第11章）です。どれも同じ形に書けます。

```
s(n+2) = p × s(n+1) − q × s(n)
```

| 列 | p | q | 始まり | 並び |
|---|---:|---:|---|---|
| フィボナッチ | 1 | −1 | 0, 1 | 0, 1, 1, 2, 3, 5, 8, 13, … |
| リュカ | 1 | −1 | 2, 1 | 2, 1, 3, 4, 7, 11, 18, … |
| ペル | 2 | −1 | 0, 1 | 0, 1, 2, 5, 12, 29, 70, … |
| 2ⁿ | 3 | 2 | 1, 2 | 1, 2, 4, 8, 16, 32, … |
| n | 2 | 1 | 0, 1 | 0, 1, 2, 3, 4, 5, … |
| cos の表（第11章） | 2c(1) | 1 | 1, c(1) | 3120 番地で 1 に戻る |

p と q は小さな整数なので、掛け算は足すことの繰り返しで済みます。

```python:code/b13_recur.py
def seq(p, q, a, b, n):
    out = [a, b]
    while len(out) < n:
        out.append(p * out[-1] + -(q * out[-2]))
    return out[:n]
```

## 15.2 続く二つを点にする

列の続く二つ (s(n), s(n+1)) を、平面の点 (a, b) として置きます。一歩進むと、点は (a, b) → (b, p·b − q·a) と動きます。

この動きで、次の量は一歩ごとに q 倍されます。

```
b² − p·a·b + q·a²
```

q = 1 なら、この量は変わりません。点は、この量が一定の線の上を動きます。

| 列 | b² − p·a·b + q·a² の並び |
|---|---|
| フィボナッチ | 1, −1, 1, −1, …（q = −1 なので一歩ごとに符号が裏返る） |
| リュカ | −5, 5, −5, 5, … |
| ペル | 1, −1, 1, −1, … |
| n | 1, 1, 1, 1, … |

第8章の Z[φ] のノルム、第12章の双曲線 x² − y² も、この量の仲間です。

## 15.3 回る・まっすぐ・開く

q = 1 にして、p だけを変えます。点が動く線 b² − p·a·b + a² = 1 の形は、

```
D = p² − 4
```

の符号で三つに分かれます。

| p | D | 線の形 | 点の動き | (0, 1) に戻るまで |
|---:|---:|---|---|---|
| −1 | −3 | 楕円 | 回る | 3 歩 |
| 0 | −4 | 楕円 | 回る | 4 歩 |
| 1 | −3 | 楕円 | 回る | 6 歩 |
| 2 | 0 | 平行な二本の直線 | まっすぐ進む | 戻らない |
| −2 | 0 | 平行な二本の直線 | 向きを裏返しながら進む | 戻らない |
| 3 | 5 | 双曲線 | 開く | 戻らない |
| 4 | 12 | 双曲線 | 開く | 戻らない |

- **回る**（D が負）：点は楕円の上を回り、整数の点のまま始めの点に戻ります。整数の p で戻るのは、3 歩・4 歩・6 歩の三通りだけです。
- **まっすぐ**（D が 0）：p = 2 では列は 0, 1, 2, 3, … と一つずつ増え、点は直線の上を等間隔に進みます。回ると開くの境目です。
- **開く**（D が正）：p = 3 では列は 0, 1, 3, 8, 21, 55, … で、フィボナッチ数の一つおきです。第12章で φ² を掛けた一歩と同じ列で、点は双曲線の上を遠ざかります。

第11章の cos の表は、p = 2c(1) を 2 よりわずかに小さく取った列です。D がわずかに負なので、点は楕円の上をゆっくり回り、3120 歩で戻ります。

## 15.4 五歩で戻る回転は、Z[φ] にある

整数の p では、五歩で戻る回転はありません。p を Z[φ] の数（整数の組 a + bφ、第8章）にすると、五歩と十歩が加わります。

| p | (0, 1) に戻るまで |
|---|---|
| −1 | 3 歩 |
| 0 | 4 歩 |
| 1 | 6 歩 |
| φ − 1 | 5 歩 |
| −φ | 5 歩 |
| φ | 10 歩 |
| 1 − φ | 10 歩 |

p = a + bφ の a, b を −6〜6 の範囲で全部試すと、戻るのはこの七つだけでした。

p = φ − 1 の列は、0, 1, φ − 1, 1 − φ, −1, 0, … です。どの数も整数の組のまま動き、b² − p·a·b + a² はどの一歩でも 1 です。

```python:code/b13_recur.py
def zmul(u, v):
    a, b = u
    c, d = v
    return (a * c + b * d, a * d + b * c + b * d)      # φ² = φ + 1
```

整数の平面で回れるのは三角・四角・六角の向きだけで、五角の向きは φ を持ち込んで初めて出ます。

## 15.5 畳み込み：ずらして掛けて足す

二つの列を **畳み込む** とは、一方を一つずつずらしながら、重なった所を掛けて足すことです。

```
(x を y で畳み込んだもの)[k] = x[0]·y[k] + x[1]·y[k−1] + … + x[k]·y[0]
```

```python:code/b13_recur.py
def conv(x, y, n=None):
    if n is None:
        n = len(x) + len(y) - 1
    out = [0] * n
    for i, xi in enumerate(x):
        for j, yj in enumerate(y):
            if i + j < n:
                out[i + j] += xi * yj
    return out
```

(1, 1) を自分自身と何回も畳み込むと、パスカルの三角形の段が出ます（6 回で 1, 6, 15, 20, 15, 6, 1）。第14章で差分の表を戻すのに使った三角形です。

## 15.6 漸化式は、畳み込みで列が消えること

フィボナッチ数の列を、短い列 (1, −1, −1) と畳み込みます。

```
フィボナッチ      0, 1, 1, 2, 3, 5, 8, 13, 21, …
× (1, −1, −1)     0, 1, 0, 0, 0, 0, 0, 0, 0, …
```

先頭の 0, 1 だけが残り、あとはすべて 0 になります。k 番目の値は s(k) − s(k−1) − s(k−2) で、漸化式そのものだからです。

漸化式 s(n+2) = p·s(n+1) − q·s(n) は、「(1, −p, q) と畳み込むと、先頭だけを残して消える」と言い直せます。ペルなら (1, −2, −1) で消えます。

逆に、残った先頭 (0, 1) から、(1, −p, q) の畳み込みを戻すと、元の列が出ます。戻す手順は、漸化式で列を作る手順そのものです。

二つの列を畳み込んだものは、二つの短い列を畳み込んだもので消えます。

```
フィボナッチ × フィボナッチ   0, 0, 1, 2, 5, 10, 20, 38, 71, …
(1, −1, −1) × (1, −1, −1)     1, −2, −1, 2, 1
これで畳み込むと              0, 0, 1, 0, 0, 0, …
```

## 15.7 整数の掛け算も畳み込み

第4章の筆算の掛け算は、桁の畳み込みと繰り上がりです。

```
1234 × 5678
桁（下の桁から） 4, 3, 2, 1  と  8, 7, 6, 5
畳み込み         32, 52, 61, 60, 34, 16, 5
繰り上げ         7006652
```

繰り上げる前の 32, 52, 61, … は、桁ごとに掛けて足しただけの数です。繰り上げは、10 を引けるだけ引いて上の桁に 1 を足すことです。

## 15.11 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。この章は、既存の線形漸化式と畳み込みを整数の上に並べたもので、それ以上のことは主張しません。

- s(n+2) = p·s(n+1) − q·s(n) は「定数係数の二階線形漸化式」です。x² − p·x + q を特性多項式と呼び、D = p² − 4q はその判別式です。D の符号で、二次形式 b² − p·a·b + q·a² の等高線が楕円・放物線型（退化）・双曲線に分かれることは、二次形式の標準的な分類です。
- q = 1 の列は、行列 [[0, 1], [−1, p]] を掛けることにあたり、その行列式が 1 なので二次形式が保たれます。q = −1 の列（フィボナッチ・ペル）では符号が一歩ごとに裏返り、これはカッシーニの恒等式にあたります。
- 整数の行列で有限の回数で戻る回転は 1・2・3・4・6 回のものだけ、という事実を「結晶学的制限定理」と呼びます。五回対称が整数の格子に入らず、準結晶（ペンローズ・タイリング）では φ が必要になることと同じ事実です。p = φ − 1, −φ, φ, 1 − φ は、それぞれ 2cos72°, 2cos144°, 2cos36°, 2cos108° です。
- 第11章の cos の表の漸化式は、チェビシェフ多項式の漸化式です。
- 列を係数とする式 s(0) + s(1)x + s(2)x² + … を母関数と呼びます。畳み込みは母関数の掛け算で、「(1, −p, q) で消える」は母関数が (先頭の式) ÷ (1 − p·x + q·x²) と書けることにあたります。
- 筆算の掛け算が桁の畳み込みであることは、高速な掛け算（数論変換・FFT による掛け算）の出発点です。
- 確かめた範囲 [計算]：
  - 上の実行例の数を確かめました。
  - Z[φ] の p について、a, b を −6〜6 の範囲（169 通り）で、60 歩以内に (0, 1) に戻るものを全部探しました。結晶学的制限定理の一般の形は、上の知識によるものです。

## 15.12 この章のまとめ

前の二つから次を作る列は、点の動きとしても、畳み込みとしても読めます。

- s(n+2) = p·s(n+1) − q·s(n) の続く二つを点にすると、b² − p·a·b + q·a² は一歩ごとに q 倍されます。q = 1 なら変わりません。
- D = p² − 4 の符号で、点は回る・まっすぐ進む・開くに分かれます。整数の p で戻るのは 3・4・6 歩だけで、Z[φ] の p にすると 5 歩と 10 歩が加わります。
- 漸化式は、短い列 (1, −p, q) と畳み込むと先頭だけを残して消えること、と言い直せます。先頭から戻す手順が、漸化式で列を作る手順です。
- 整数の掛け算も、桁の畳み込みと繰り上がりです。

次の章では、この畳み込みを φ の数で回す変換（φ-NTT と coneFFT）に進みます。
