# 第9章　根：√n・連分数・ペル

## 9.1 √5 は近づけなくてよい

第8章までで、√5 は近づける必要のない数になりました。

```
√5 = 2φ − 1
```

√5 は整数の組 (−1, 2) として、そのまま持てます。φ の世界の中では、√5 は無理数として扱わなくてよい数です。

この章では、それ以外の √n（√2, √3, √13, …）を、足し算だけで近づけます。道具は三つです。

| 道具 | やること | 出るもの |
|---|---|---|
| 奇数を引く | 1, 3, 5, … を引けるだけ引く | √n の整数部分 |
| 桁ごとの開平 | 2 桁ずつ下ろして、奇数を引けるだけ引く | √n の小数を好きな桁まで |
| 長方形を切る | 横 √n・縦 1 の長方形から正方形を切り取る | 連分数と近似分数 |

## 9.2 奇数を引けるだけ引く

第7章で、平方は奇数を順に足したものでした。逆に、n から奇数 1, 3, 5, … を引けるだけ引くと、引けた回数が √n の整数部分です。

```python:code/b13_roots.py
def isqrt_odd(n: int) -> Tuple[int, int]:
    """奇数を引けるだけ引く。戻り値 (√n の整数部分, 残り)。"""
    k, odd = 0, 1
    while n >= odd:
        n += -odd
        odd += 2
        k += 1
    return k, n
```

## 9.3 桁ごとの開平

小数の桁が欲しいときは、2 桁ずつ下ろします。下ろすたびに、「これまでの答えの 20 倍 + 1」から始まる奇数を引けるだけ引きます。引けた回数が次の桁です。

```python:code/b13_roots.py
def sqrt_digits(n: int, places: int) -> str:
    """√n を小数 places 桁まで、桁ごとの開平で。各桁は奇数を引けるだけ引いた回数。"""
    ...
    for pr in pairs:
        r = times(100, r) + pr          # 2 桁下ろす
        odd = times(20, p) + 1          # 今回の奇数の始まり
        c = 0
        while r >= odd:                 # 引けるだけ引く
            r += -odd
            odd += 2
            c += 1
        p = times(10, p) + c            # 答えに 1 桁つなぐ
        digits.append(str(c))
```

`times(k, x)` は、x を k 回足すことです。この方法なら、小数を何桁でも、足し算と引き算だけで出せます。

## 9.4 長方形を切る：連分数

第6章では、長方形から正方形を切り取って、最大公約数を求めました。同じことを、横 √n・縦 1 の長方形でやります。

√n は割り切れないので、切り取りは終わりません。それでも、同じ大きさの正方形が何枚ずつ取れるかを並べると、ある所から同じ並びが繰り返します。この並びが、√n の **連分数** です。

| 長方形 | 連分数 | 繰り返す部分 |
|---|---|---|
| φ × 1 | [1; 1, 1, 1, …] | 1（第6章のフィボナッチの長方形） |
| √2 × 1 | [1; 2, 2, 2, …] | 2 |
| √3 × 1 | [1; 1, 2, 1, 2, …] | 1, 2 |
| √5 × 1 | [2; 4, 4, 4, …] | 4 |
| √13 × 1 | [3; 1, 1, 1, 1, 6, …] | 1, 1, 1, 1, 6 |

連分数の項は、整数だけの漸化式で出せます。長方形の絵を描かなくても、同じ並びが出ます。

```python:code/b13_roots.py
def cf_sqrt(n: int, terms: int) -> List[int]:
    """√n の連分数の項 a0; a1, a2, …（整数の漸化式）。"""
    a0, rest = isqrt_odd(n)
    if rest == 0:
        return [a0]
    out = [a0]
    m, d, a = 0, 1, a0
    for _ in range(terms - 1):
        m = times(a, d) + -m                       # m ← d·a − m
        q, r = ladder_div(n + -(m * m), d)         # d ← (n − m²) ÷ d（割り切れる）
        assert r == 0
        d = q
        a, _ = ladder_div(a0 + m, d)               # a ← (a0 + m) ÷ d の整数部分
        out.append(a)
    return out
```

割り算は第6章の倍々の梯子（`ladder_div`）で、足し算と引き算だけで済みます。

## 9.5 近似分数とペル方程式

切り取りを途中で止めると、そこまでの長方形から分数 p/q が一つ読めます。これを **近似分数** と呼びます。

```
p(k) = a(k) × p(k−1) + p(k−2)        （a(k) 回足して、二つ前を足す）
q(k) = a(k) × q(k−1) + q(k−2)
```

フィボナッチ数の作り方と同じ形です。φ ならすべての a(k) が 1 なので、p も q もフィボナッチ数そのものになります。

近似分数ごとに p² − n q² を計算すると、±1 になる行が周期の切れ目に現れます。これが **ペル方程式** x² − n y² = ±1 の解です。

| n | 一番小さい解 | x² − n y² | ひとこと |
|---:|---|---:|---|
| 2 | 1² − 2·1² | −1 | |
| 3 | 2² − 3·1² | +1 | |
| 5 | 2² − 5·1² | −1 | 2 + √5 = φ³ |
| 7 | 8² − 7·3² | +1 | |
| 13 | 18² − 13·5² | −1 | 324 − 325 |
| 19 | 170² − 19·39² | +1 | |
| 61 | 29718² − 61·3805² | −1 | 小さい n でも解が大きい |

ペル方程式は、第8章のノルム ±1（単数）を、√n の世界に移したものです。φ の世界の単数 a² + ab − b² = ±1 が、√n の世界では x² − n y² = ±1 になります。

## 9.9 観察者側の整理

既存の数学の名前との対応です。確かめた範囲の行のほかは、Claude の知識によるもので、この本では検算していません。

- 2 桁ずつ下ろして奇数を引く開平は、そろばんや筆算の開平法と同じ手順です。
- 平方数でない n について、√n の連分数が a0 の直後から周期的になり、周期の最後の項が 2·a0 になることは、ラグランジュが示しました。
- x² − n y² = ±1 の一番小さい解が周期の切れ目の近似分数に現れることは、ペル方程式の古典的な解法です（ブラーマグプタ、バースカラ2世のチャクラヴァーラ法、のちにオイラーとラグランジュ）。周期の長さが奇数なら −1 の解があります（√13 の周期は 5）。
- 確かめた範囲 [計算]：
  - 奇数を引く整数平方根を、0〜4999 で確かめました。
  - 桁ごとの開平を、n = 2, 3, 5, 7, 13, 99, 12345 で小数 40 桁まで確かめました。
  - 2〜299 の平方数でない n で、周期の切れ目の近似分数が x² − n y² = ±1 を満たすことを確かめました。
  - √5 の近似分数がリュカ数とフィボナッチ数の半分になっているのは、上の実行例の 2 組から読んだ観察です。

## 9.10 この章のまとめ

根は、引けるだけ引くことと、長方形を切ることで近づけられます。

- √5 は 2φ − 1 として持てるので、近づける必要がありません。
- √n の整数部分は、奇数を引けるだけ引いた回数です。小数は、2 桁ずつ下ろして同じことを続ければ何桁でも出ます。
- 横 √n・縦 1 の長方形から正方形を切り取った枚数の並びが、連分数です。
- 近似分数はフィボナッチ数と同じ足し方で伸び、周期の切れ目でペル方程式 x² − n y² = ±1 の解になります。

ここで第2部（演算）が終わります。第3部では、ここまでの道具で関数（指数・対数・三角関数・双曲関数・定数）を作ります。
